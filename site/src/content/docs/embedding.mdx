If you want more control over how your Squiffy story is presented, you can embed it in your own HTML page. This allows you to customize the layout, add your own styling, or integrate the story into an existing website.

## Basic setup

First, export your story using the CLI with `--scriptonly`:

```
npx @textadventures/squiffy-cli mygame.squiffy --scriptonly
```

This creates `story.js` containing your compiled story.

You'll also need the Squiffy runtime and its stylesheet. You can either:
- Run a full export first and keep `squiffy.runtime.global.js` and `style.css`
- Or load them from a CDN such as jsDelivr, which serves the [`squiffy-runtime`](https://www.npmjs.com/package/squiffy-runtime) npm package. Use the same version of Squiffy that you compiled your story with. For the current version ({version}), that's:

<Code lang="html" code={`<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/squiffy-runtime@${version}/dist/squiffy.runtime.css">
<script src="https://cdn.jsdelivr.net/npm/squiffy-runtime@${version}/dist/squiffy.runtime.global.js"></script>`} />

Here's a minimal HTML page that runs a Squiffy story:

```html
<!DOCTYPE html>
<html>
<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>My Story</title>
    <link rel="stylesheet" href="style.css">
    <script src="squiffy.runtime.global.js"></script>
    <script src="story.js"></script>
</head>
<body>
    <div id="squiffy"></div>
    <script>
        document.addEventListener('DOMContentLoaded', async function () {
            const squiffyApi = await squiffyRuntime.init({
                element: document.getElementById('squiffy'),
                story: story,
            });
            await squiffyApi.begin();
        });
    </script>
</body>
</html>
```

## Using Vite

If you're building a web app with [Vite](https://vite.dev), the Squiffy Vite plugin lets you import `.squiffy` files directly. They're compiled as part of your build, so there's no separate export step:

```
npm install --save-dev @textadventures/vite-plugin-squiffy
npm install squiffy-runtime
```

Add the plugin to `vite.config.ts`:

```ts
import { defineConfig } from "vite";
import squiffy from "@textadventures/vite-plugin-squiffy";

export default defineConfig({
    plugins: [squiffy()],
});
```

Then import your story and pass it to `init()`:

```ts
import { init } from "squiffy-runtime";
import "squiffy-runtime/squiffy.runtime.css";
import { story } from "./mygame.squiffy";

const squiffyApi = await init({
    element: document.getElementById("squiffy")!,
    story,
});
await squiffyApi.begin();
```

While Vite's dev server is running, it recompiles the story whenever you save a `.squiffy` file, including files pulled in with `@import`. With a few more lines, you can update the running story without losing the player's progress. See the [plugin's README](https://github.com/textadventures/squiffy/tree/main/vite-plugin) for that, and for TypeScript setup. There's a complete example in [`examples/vite-app`](https://github.com/textadventures/squiffy/tree/main/examples/vite-app).

The options and API below are the same whichever way you load the story. With Vite, `init` is imported from `squiffy-runtime` rather than called as `squiffyRuntime.init`.

## Initialization options

The `squiffyRuntime.init()` function accepts an options object:

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `element` | `HTMLElement` | (required) | The container element for the story output |
| `story` | `Story` | (required) | The compiled story object (from `story.js`) |
| `persist` | `boolean` | `true` | Whether to save state to localStorage |
| `storyId` | `string` | URL path (or the story's ID when opened from a local file) | Key used for localStorage (allows multiple stories on same domain) |
| `scroll` | `string` | `"body"` | Scroll behavior: `"body"`, `"element"`, or `"none"` |
| `onSet` | `function` | - | Callback when an attribute is set |

### Persistence

By default, Squiffy saves the player's progress to localStorage, so they can return to where they left off. The `storyId` option determines the storage key:

```javascript
const squiffyApi = await squiffyRuntime.init({
    element: document.getElementById('squiffy'),
    story: story,
    persist: true,
    storyId: 'my-unique-story-id',
});
```

Set `persist: false` to disable saving:

```javascript
const squiffyApi = await squiffyRuntime.init({
    element: document.getElementById('squiffy'),
    story: story,
    persist: false,
});
```

### Scroll behavior

The `scroll` option controls how the page scrolls when new content appears:

- `"body"` (default) - Scrolls the page body
- `"element"` - Scrolls within the container element (useful for fixed-height containers)
- `"none"` - No automatic scrolling

```javascript
const squiffyApi = await squiffyRuntime.init({
    element: document.getElementById('squiffy'),
    story: story,
    scroll: 'element',
});
```

## API methods

The `init()` function returns a `SquiffyApi` object with these methods:

### begin()

Starts or resumes the story. Call this after initialization:

```javascript
await squiffyApi.begin();
```

### restart()

Restarts the story from the beginning, clearing saved state:

```javascript
squiffyApi.restart();
```

### get(attribute)

Gets the value of a story attribute:

```javascript
const score = squiffyApi.get('score');
const hasKey = squiffyApi.get('hasKey');
```

### set(attribute, value)

Sets a story attribute:

```javascript
squiffyApi.set('score', 100);
squiffyApi.set('playerName', 'Alice');
```

### goBack()

Goes back to the previous section or passage (undo):

```javascript
squiffyApi.goBack();
```

## Events

You can listen for events using `on()`, `off()`, and `once()`:

### linkClick

Fired when a story link is clicked:

```javascript
squiffyApi.on('linkClick', (event) => {
    console.log('Link type:', event.linkType); // "section", "passage", "rotate" or "sequence"
});
```

### set

Fired when an attribute value changes:

```javascript
squiffyApi.on('set', (event) => {
    console.log(`${event.attribute} = ${event.value}`);
});
```

### canGoBackChanged

Fired when the ability to go back changes:

```javascript
squiffyApi.on('canGoBackChanged', (event) => {
    backButton.disabled = !event.canGoBack;
});
```

### Unsubscribing

The `on()` method returns an unsubscribe function:

```javascript
const unsubscribe = squiffyApi.on('linkClick', handler);

// Later, to stop listening:
unsubscribe();
```

Or use `off()`:

```javascript
squiffyApi.off('linkClick', handler);
```

## Complete example

Here's a more complete example with custom controls:

```html
<!DOCTYPE html>
<html>
<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>My Story</title>
    <link rel="stylesheet" href="style.css">
    <script src="squiffy.runtime.global.js"></script>
    <script src="story.js"></script>
    <style>
        #controls {
            padding: 10px;
            background: #f0f0f0;
            margin-bottom: 20px;
        }
        #squiffy {
            max-width: 800px;
            margin: 0 auto;
            padding: 20px;
        }
        button:disabled {
            opacity: 0.5;
        }
    </style>
</head>
<body>
    <div id="controls">
        <button id="restart">Restart</button>
        <button id="back" disabled>Back</button>
        <span id="status"></span>
    </div>
    <div id="squiffy"></div>
    <script>
        document.addEventListener('DOMContentLoaded', async function () {
            const squiffyApi = await squiffyRuntime.init({
                element: document.getElementById('squiffy'),
                story: story,
                persist: true,
                storyId: window.location.pathname,
            });

            const backButton = document.getElementById('back');
            const statusEl = document.getElementById('status');

            // Restart button
            document.getElementById('restart').addEventListener('click', function () {
                if (confirm('Are you sure you want to restart?')) {
                    squiffyApi.restart();
                }
            });

            // Back button
            backButton.addEventListener('click', function () {
                squiffyApi.goBack();
            });

            // Update back button state
            squiffyApi.on('canGoBackChanged', (event) => {
                backButton.disabled = !event.canGoBack;
            });

            // Show score changes
            squiffyApi.on('set', (event) => {
                if (event.attribute === 'score') {
                    statusEl.textContent = `Score: ${event.value}`;
                }
            });

            await squiffyApi.begin();
        });
    </script>
</body>
</html>
```

## Styling

Squiffy adds CSS classes to its output that you can style:

- `.squiffy-output-section` - Container for each section
- `.squiffy-output-passage` - Container for each passage
- `.squiffy-link` - All clickable links
- `.squiffy-link.disabled` - Links that have been clicked/disabled

You can include the default styles from a full export (`style.css`) and customize from there, or write your own styles from scratch. See [Customising styles](/styling/) for a reference to the default styles.
