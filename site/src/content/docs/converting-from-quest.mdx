Squiffy can convert a gamebook made in the gamebook mode of [Quest Viva](https://questviva.com), or of Quest 5 as it was known before, into a Squiffy story. Each page becomes a section, and its links become Squiffy links, so the story plays the same way, and you can carry on writing it in Squiffy's [editor](/editor/), with its [story map](/story-map/).

Only gamebooks can be converted. Quest's text adventures work very differently from Squiffy, and aren't converted.

## Converting a gamebook

You can convert a gamebook from either kind of Quest file:

- **A `.quest` file**, which is what Quest 5 and Quest Viva publish, and what you download from textadventures.co.uk. It has the images and sounds the gamebook uses in it, and they're copied into the converted story.
- **A `.aslx` file**, which is the file Quest saves as you write. Its images and sounds are in the same folder.
- **A `.zip` file with the `.aslx` file in it**, such as a game you download from Quest Viva. The images and sounds in the same folder as the `.aslx` file are copied into the converted story. (This is for the editor: to use the CLI, unzip it first.)

Then either:

- In the [editor](/editor/), choose **Open file** on the home page and pick the Quest file. The editor says what it is and asks before converting it. On the web, the converted story is kept in your browser. In the [desktop app](/desktop-app/), you choose a folder to put it in. On the web, the editor can only read the file you give it, so if you give it a `.aslx` file, add its images and sounds to the story afterwards: `quest-import.txt` lists them.
- With the [command-line tool](/cli/#converting-from-quest), run:

  ```bash
  npx @textadventures/squiffy-cli mygame.quest --convert-quest
  ```

  This puts the converted story in a new folder next to the file, called `mygame`, with the images and sounds the gamebook uses. Use `--out` to choose another folder.

## What you get

The converted story is a folder with:

- `story.squiffy`, the story itself. Each page becomes a section with the same name, and a page with no links, and no script that goes to another page, is marked as one of the story's [endings](/basic-concepts/#endings).
- `squiffy.json`, the [project file](/multiple-files/).
- `story.css`, if you chose the gamebook's colours, fonts or page width in Quest. They're set with Squiffy's [style variables](/styling/), and the story stays in light mode, as it did in Quest. Without one, the story follows Squiffy's own styles, in light and dark mode.
- The images and sounds the gamebook uses.
- `quest-import.txt`, which lists everything that couldn't be converted exactly, page by page.

In Quest, the pages a player has read stay on the screen as they go, as they do in Squiffy. If you set your gamebook to clear the screen before each page, the story starts with a [master section](/basic-concepts/#master-sections-and-passages) that does the same.

Anything that couldn't be converted at all is kept in the story as a comment, so nothing's lost:

```squiffy
{{!-- Quest: {either lamp:The lamp is on.|It's dark.} --}}
```

Search for `Quest:` to find them all.

<Aside>
Play the story through after converting it. The editor's [story map](/story-map/) is a good way to get to know the converted story, and to spot links that go nowhere.
</Aside>

## How it converts

| Quest | Squiffy |
|---|---|
| A page | A section with the same name |
| A page's links | `[[Go left]](Page2)` |
| A link page, to a web address | A link to that address, which opens in a new tab |
| A picture or YouTube video | `<img>` or a YouTube player, before the page's text |
| A page's sound | `@sound` (see [Music and sound](/images-and-files/#music-and-sound)). As in Quest, each page starts by stopping the sounds and music, with `@sound stop` and `@music stop`, unless the last page with a sound was set to continue playing it: then it's `{{#unless continuesound}}`, and pages with a sound set `continuesound` |
| `{page:Page2}`, `{page:Page2:Go left}` | `[[Page2]]`, `[[Go left]](Page2)` |
| `{if lamp:...}`, `{if not lamp:...}` | `{{#if lamp}}...{{/if}}`, `{{#if not lamp}}...{{/if}}` |
| `{if gold>5:...}`, `{if mood=happy:...}` | `{{#if gold > 5}}...{{/if}}`, `{{#if mood = "happy"}}...{{/if}}` |
| `{if Page2.visited:...}` | `{{#if (seen "Page2")}}...{{/if}}` |
| `{once:...}`, `{notfirst:...}` | `{{#once}}...{{/once}}`, `{{#once}}{{else}}...{{/once}}` (see [The first time](/dynamic-text/#the-first-time)) |
| `{counter:gold}`, `{game.name}` | `{{= gold + 0}}` (which shows 0 before it's set, as Quest does), `{{name}}` |
| `{random:red:green:blue}` | `{{random (array "red" "green" "blue")}}` |
| `{img:map.png}` | `<img src="map.png">` |
| `{b:...}`, `{i:...}`, `{u:...}`, `{s:...}`, `{colour:red:...}`, `{back:yellow:...}` | Bold, italic and so on, and `<span style="...">` |
| `{popup:key:An old key.}` | A [passage](/basic-concepts/#passages) link, `[key](key)`, that shows the text |
| The gamebook's title, subtitle and author | Shown at the start, as in Quest, and the title is the story's `@title` |

Quest's flags and counters become [attributes](/attributes/) with the same names. An attribute of the player or of a page, such as `player.strength`, becomes `player_strength`. A name Squiffy uses itself, such as `seen` or `turns`, gets an underscore: `seen_`.

## How scripts convert

A page's script runs before its text is shown, so it becomes text at the start of the page's section. Squiffy's helpers, such as `{{set}}` and `{{#if}}`, run in order as the text is shown, so the page's text and links see what the script did. The game's script that runs on every page goes in the [master section](/basic-concepts/#master-sections-and-passages), `[[]]`, which runs with every section.

| Quest | Squiffy |
|---|---|
| `msg ("You have " + game.gold + " gold.")` | `You have {{gold}} gold.` |
| `SetFlagOn ("lamp")`, `SetFlagOff ("lamp")` | `{{set "lamp" true}}`, `{{set "lamp" false}}` |
| `SetCounter ("gold", 10)`, `IncreaseCounter ("gold")`, `DecreaseCounter ("gold")`, `ChangeCounter ("gold", 5)` | `{{set "gold" 10}}`, `{{inc "gold"}}`, `{{dec "gold"}}`, `{{inc "gold" 5}}` |
| `game.name = "Bob"`, `player.strength = player.strength + 1` | `{{set "name" "Bob"}}`, `{{set "player_strength" player_strength + 1}}` |
| `if (GetBoolean(game, "lamp")) { } else if (...) { } else { }` | `{{#if lamp}}...{{else if ...}}...{{else}}...{{/if}}` |
| `GetInt(game, "gold") >= 10`, `HasSeenPage(Page2)`, `player.parent = Page2` | `gold >= 10`, `(seen "Page2")`, `(at "Page2")` |
| `RandomChance(25)` | `(random (array 1 2 3 4)) <= 1`, true a quarter of the time |
| `switch (...) { case (...) { } }` | `{{#if}}` and `{{else if}}` |
| `firsttime { } otherwise { }` | `{{#once}}...{{else}}...{{/once}}`. Anywhere but the start of a page's script, it has a name, such as `{{#once "firsttime_1"}}`, as the script may be shown from more than one place |
| `MovePlayer (Page2)` | `{{goto "Page2"}}` |
| `AddPageLink (Page1, Page2, "Go on")`, `RemovePageLink (Page1, Page2)` | An attribute for the link, which Page1 checks before showing it: see below |
| `GetInput () { game.name = result }` | A text box, and a **Continue** link to a section that runs the rest, `{{set "name" input}}`, and shows the page's links again |
| `ClearScreen`, before the script shows anything | `@clear` |
| `picture ("map.png")`, `play sound ("door.mp3", false, false)` | `<img>`, `{{sound "door.mp3"}}` |
| `play sound ("rain.mp3", false, true)`, which loops, and `stop sound` | [Music](/images-and-files/#music-and-sound), `{{music "rain.mp3"}}`, and `{{stopsounds}}{{stopmusic}}` |
| `PrintCentered`, `TextFX_Typewriter`, `DisplayHttpLink`, `ShowYouTube` | Centred text, `{{#animate "typewriter"}}`, a web link, a YouTube player |
| `SetBackgroundColour`, `SetForegroundColour`, `SetFontName`, `SetWebFontName`, `SetFontSize` | A `<style>` that sets Squiffy's [style variables](/styling/) from then on |

A link that a script adds or removes is shown with `{{#if}}`, and the scripts set its attribute, named after its pages, such as `link_Page1_Page2`. If the link starts on the page, the story sets the attribute when it starts. If scripts give a link different texts, its attribute says which one to show, counting from 1:

```squiffy
{{#if link_Page1_Page2}}
[[Go on]](Page2)
{{/if}}
```

`MovePlayer` goes to the other page once the page is shown. In Quest, the rest of a page with text wasn't shown, but here its text and links are shown first. `quest-import.txt` lists the pages where this happens.

## What isn't converted yet

- **Script commands beyond the gamebook editor's own**, such as lists, loops, `ShowMenu`, `wait`, your own functions, and Quest's JavaScript (`JS.`...), are kept as comments. So is a `ClearScreen` after the script has shown something, as Squiffy can only clear the screen before showing a section.
- **Expressions in text**: `{either ...}`, `{eval:...}` and `{=...}`.
- **Commands for Quest's text adventures**, such as `{object:...}` and `{exit:...}`, and `{select:...}` and `{rndalt:...}`.
- **Links and other commands in `{random:...}`.** Its choices can be text, formatting and images.
- **`TextFX_Unscramble`**, which is typed out instead.
- **JavaScript** written for Quest.
