A Squiffy story is an ordinary web page, so you change how it looks with CSS. This page explains where Squiffy's styles come from, how to override them, and which rules control what.

## Where to put your styles

There are two ways to add your own CSS:

- **In your story:** put your rules in a CSS file in your story's folder, and [import](/multiple-files/#importing-files) it with `@import my_style.css`. In the editor, choose **Stylesheet** from the **+** menu in the files list. The editor adds the `@import` for you, and the new file starts with the most common changes and their defaults, ready to uncomment. The published `index.html` links to it *after* Squiffy's own styles, so your rules take precedence, and your changes are kept every time you publish. The editor's preview uses it too.
- **Your own page:** if you [embed Squiffy in a custom page](/embedding/), you control the HTML and CSS completely.

<Aside>
When you override a rule, you only need to include the properties you're changing. For example, to change the link colour, `a.squiffy-link { color: darkgreen; }` is enough. Everything else keeps its default.
</Aside>

## Light and dark mode

A story follows the reader's light or dark system setting. Readers can also switch between light and dark with the button next to Restart, and their choice is remembered the next time they open the story. All of Squiffy's colours are [CSS variables](#colours), each with a light and a dark value, so changing a colour is usually just a matter of setting a variable.

To keep a story in light mode whatever the reader's setting (or in dark mode, with `dark`):

```css
:root {
    color-scheme: light;    /* default: light dark */
}
```

This also hides the light/dark button, as it would have no effect. Do this if your own CSS sets a background or text colour for one mode only. For example, a story that sets `body { background-color: white; }` would show light text on a white background in dark mode.

In the editor, the preview follows the editor's own theme, which you choose in **Settings**. A story that sets `color-scheme` keeps its own setting in the preview too.

## Common changes

### Fonts, text size and page width

Set these variables to change the story's font and the width of the page:

```css
:root {
    --squiffy-font-family: "Helvetica Neue", Arial, sans-serif;  /* default: Charter, …, Georgia, serif */
    --squiffy-font-size: 1.25rem;                                /* default: 1.125rem */
    --squiffy-line-height: 1.5;                                  /* default: 1.6 */
    --squiffy-max-width: 50rem;                                  /* default: 42rem */
}
```

| Variable | What it sets | Default |
| --- | --- | --- |
| `--squiffy-font-family` | The font of the story and the header | Charter, Sitka Text, Cambria or Georgia, whichever the reader has |
| `--squiffy-font-size` | The size of the story text. The header's buttons stay the same size | `1.125rem` |
| `--squiffy-line-height` | The space between lines of text | `1.6` |
| `--squiffy-max-width` | The width of the story text | `42rem` |

Sizes are in `rem`, so they scale with the text size the reader has chosen in their browser (`1rem` is usually 16 pixels).

### Colours

Set these variables to change Squiffy's colours. `light-dark()` gives a colour for each mode, so the story still works in both:

```css
:root {
    --squiffy-background: light-dark(#fdf6e3, #1e1e2e);
    --squiffy-text: light-dark(#3b3227, #e0e0e0);
    --squiffy-link: light-dark(darkgreen, lightgreen);
    --squiffy-link-hover: light-dark(green, palegreen);
}
```

If you've [kept your story in one mode](#light-and-dark-mode), you can give just one colour: `--squiffy-link: darkgreen;`.

| Variable | What it colours | Light | Dark |
| --- | --- | --- | --- |
| `--squiffy-background` | The page background | `#ffffff` | `#18181b` |
| `--squiffy-text` | The story text | `#1f2328` | `#e4e4e7` |
| `--squiffy-link` | Links, [continue](/dynamic-text/#animation) links and the keyboard focus outline | `#1d5fd6` | `#7aa7ff` |
| `--squiffy-link-hover` | Links under the mouse pointer | `#0f3f99` | `#b0cbff` |
| `--squiffy-muted` | The Back, Save, Restart and light/dark buttons, and links waiting for [valid input](/player-input/#input-validation) | `#6b6f76` | `#9a9ca3` |
| `--squiffy-border` | The lines between sections | `#e2e2e6` | `#34343a` |
| `--squiffy-error` | Inputs that fail validation | `#c62828` | `#ff7b72` |
| `--squiffy-success` | Inputs that pass validation | `#2e7d32` | `#6cc070` |

### Link colour

Links are `a.squiffy-link`. The easiest way to change their colour is with the `--squiffy-link` and `--squiffy-link-hover` [variables](#colours). The underline is the same colour as the text, so you can also change the colour with a rule:

```css
a.squiffy-link {
    color: darkgreen;      /* default: var(--squiffy-link) */
}

a.squiffy-link:hover {
    color: limegreen;      /* default: var(--squiffy-link-hover) */
}
```

Once the player has moved on to a new section, the old links are disabled. They are shown in the same colour as the surrounding text, without an underline.

### Section dividers

When the player moves on, a faint line separates each section from the next. Change its colour with `--squiffy-border`, or to remove it:

```css
div.squiffy-output-section:not(:last-child),
div.squiffy-output-passage:not(:last-child),
div.squiffy-output-block:not(:last-child) {
    border-bottom: none;     /* default: 1px solid var(--squiffy-border) */
}
```

### Styling a particular section

Each section's output has a `data-section` attribute with the section's name, and each passage has a `data-passage` attribute, so you can style one on its own:

```css
.squiffy-output-section[data-section="The cellar"] {
    background-color: #222;
    color: #ddd;
}
```

### The header

The Back, Restart and light/dark buttons are in a header that stays at the top of the window as the story scrolls under it. Its background is `--squiffy-background`, so if you change the page's background, set that [variable](#colours) rather than styling `body`. To make the header scroll away with the story instead:

```css
div#squiffy-header {
    position: static;
}

div#squiffy-header::after {
    display: none;     /* the fade under the header */
}
```

### Hiding the light/dark button

To follow the reader's system setting without offering them the button:

```css
button#squiffy-theme {
    display: none;
}
```

### Hiding the Back button

To leave out the Back button, set `"backButton": false` in your story's [`squiffy.json`](/multiple-files/#the-back-button), rather than hiding it with CSS.

### Hiding the Save button

To leave out the Save button, set `"saveButton": false` in your story's [`squiffy.json`](/multiple-files/#saved-games).

### Hiding the Restart button

```css
button#restart {
    display: none;
}
```

To translate the buttons' tooltips, and the message that asks the player whether they're sure they want to restart, see [The page's text in another language](/multiple-files/#the-pages-text-in-another-language).

<Aside type="caution">
If you build with the command-line tool, rebuilding overwrites `index.html`. Use `--scriptonly` to update only `story.js` once you've changed the other files. See [Using Squiffy from the command line](/cli/).
</Aside>

## Default styles reference

The exported `style.css` combines two sets of rules: the page layout, and the styles for the story text itself. These are the selectors you're most likely to want to change, with their defaults.

### Page layout

| Selector | What it is | Defaults |
| --- | --- | --- |
| `:root` | The whole page | `color-scheme: light dark`, and the [font and width variables](#fonts-text-size-and-page-width) |
| `body` | The page | `background-color: var(--squiffy-background)`, `color: var(--squiffy-text)`, no margin |
| `div#squiffy-container` | Wraps the header and the story | `max-width: var(--squiffy-max-width)`, centred, `font-family: var(--squiffy-font-family)`, `line-height: var(--squiffy-line-height)` |
| `div#squiffy-header` | The bar above the story containing the Back, Save, Restart and light/dark buttons | Stays at the top of the window (`position: sticky`), with a short fade underneath. `font-size: 0.875rem`, right-aligned |
| `button#squiffy-back`, `button#squiffy-saves-button`, `button#restart`, `button#squiffy-theme` | The Back, Save, Restart and light/dark buttons | An arrow, a floppy disk, a circular arrow, and a moon or sun |
| `div#squiffy` | The story text | `font-size: var(--squiffy-font-size)` |
| `div#squiffy img` | Images in the story | `max-width: 100%`, so they never overflow the page |

### Story text

| Selector | What it is | Defaults |
| --- | --- | --- |
| `:root` | The whole page | The [colour variables](#colours) |
| `a.squiffy-link` | Links | `color: var(--squiffy-link)`, underlined, with a short fade when the colour changes, and an outline when focused with the keyboard |
| `a.squiffy-link[data-handler="rotate"]`, `a.squiffy-link[data-handler="sequence"]` | [Rotate and sequence](/dynamic-text/#rotate) links | Dotted underline, since they change in place rather than moving the story on |
| `a.squiffy-link.disabled` | Links that can no longer be clicked | Same colour as the surrounding text, no underline |
| `a.squiffy-link.validation-disabled` | Links disabled until the player fills in the [inputs](/player-input/#input-validation) correctly | `color: var(--squiffy-muted)`, no underline |
| `button.squiffy-header-button` | The Back, Save, Restart and light/dark buttons | `color: var(--squiffy-muted)`, no border or background, with a faint background when the mouse pointer is over it. The icons are `1.25em` across |
| `.squiffy-output-section` | Each section's output | A `1px solid var(--squiffy-border)` line underneath, and a `1em` gap, except for the latest one |
| `.squiffy-output-passage` | Each passage's output | As above |
| `dialog.squiffy-saves` | The [Saved games](/multiple-files/#saved-games) dialog | In the story's colours (the variables above), with the system's own font. Its parts have classes starting `squiffy-saves-` |
| `input.squiffy-invalid` (and `textarea`, `select`) | An input that fails validation | `border-color: var(--squiffy-error)` |
| `input:valid` (and `textarea`, `select`) | An input that passes validation | `border-color: var(--squiffy-success)` |
| `.squiffy-continue` | [Continue](/dynamic-text/#animation) links | `color: var(--squiffy-link)`, underlined, like other links. Its pulse, glow and bounce animations are turned off if the reader has asked their system to reduce motion. |

The full set of rules is in [`squiffy.runtime.css`](https://github.com/textadventures/squiffy/blob/main/runtime/src/squiffy.runtime.css) and [`squiffy.page.css`](https://github.com/textadventures/squiffy/blob/main/runtime/src/squiffy.page.css) on GitHub.
