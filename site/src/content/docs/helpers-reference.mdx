Squiffy uses Handlebars as its text processing engine, providing a powerful set of helpers for dynamic content. This page is a quick reference for all available helpers. For the rest of Squiffy's syntax, such as links and directives, see the [Syntax cheat sheet](/syntax/).

## Text processing

Squiffy processes all text through Handlebars, which means you can use:
- Double curly braces `{{}}` to output values and call helpers
- Block helpers with `{{#helper}}...{{/helper}}` syntax
- Comments with `{{! comment text }}`
- Markdown formatting (converted to HTML automatically)

### Conditions

`{{#if}}`, `{{#unless}}` and `{{else if}}` accept conditions written with familiar operators:

```squiffy
{{#if class = "warrior"}}You are a warrior.{{/if}}
{{#if score > 100 and has_key}}You win!{{else}}Keep trying.{{/if}}
{{#unless (seen "intro") or count >= 3}}Welcome!{{/unless}}
```

| Operator | Meaning | Equivalent helper |
|----------|---------|-------------------|
| `=` or `==` | equal to | `eq` |
| `!=` | not equal to | `ne` |
| `>` | greater than | `gt` |
| `>=` | greater than or equal to | `gte` |
| `<` | less than | `lt` |
| `<=` | less than or equal to | `lte` |
| `contains` | has the value in it: see [Text helpers](#text-helpers) and [Querying arrays](#querying-arrays) | |
| `and` or `&&` | both are true | `and` |
| `or` or `\|\|` | either is true | `or` |
| `not` or `!` | is not true | `not` |
| `+` | add (or join text) | `add` |
| `-` | subtract | `sub` |
| `*` | multiply | `mul` |
| `/` | divide | `div` |
| `%` | remainder after dividing | `mod` |
| `? :` | one value or another: see [Choosing between two values](#choosing-between-two-values) | `cond` |

Values can be attribute names, numbers, quoted strings, `true`/`false`, or helper calls in parentheses such as `(seen "intro")` or `(length "inventory")`. For attribute names containing spaces, use square brackets: `{{#if [player name] = "Bob"}}`.

Calculations are worked out first (`*`, `/` and `%` before `+` and `-`), then comparisons (including `contains`), then `not`, then `and`, then `or`, and `? :` last of all. So `gold >= price * 2 + 1` means `gold >= ((price * 2) + 1)`, `not class = "warrior"` means `not (class = "warrior")`, and `a or b and c` means `a or (b and c)`. Use parentheses to group things differently, e.g. `(a or b) and c`. A `-` in front of a value makes it negative, e.g. `-score`.

Put spaces around `-` and `/` when they're operators. Without them they're part of a name: `my-score` is an attribute called "my-score", and `player/score` is a Handlebars path, but `my - score` subtracts.

Each condition is converted to the equivalent helpers before it runs, so `{{#if score > 100 and has_key}}` is the same as `{{#if (and (gt score 100) has_key)}}`. You can still write conditions in that form if you prefer, and you'll need it when using the comparison or logic helpers anywhere other than a condition, as described below.

### Calculations

You can also use these operators to work out a value to store or display:

```squiffy
@set gold = gold + price * 2
{{set "gold" gold + price * 2}}
{{inc "score" bonus * 10}}
{{dec "health" damage - armour}}
That costs {{= price * 2}} gold.
[[Buy]](shop, gold -= price * 2)
```

`@set` and link assignments accept an expression after the `=` (or `+=`, `-=`, `*=`, `/=`): see [Setting attributes](/attributes/#setting-attributes). `{{set}}`, `{{inc}}` and `{{dec}}` accept an expression after the attribute name. `{{= expression}}` displays the result of one. As with conditions, they're converted to helpers before they run: `{{set "gold" gold + price * 2}}` is the same as `{{set "gold" (add gold (mul price 2))}}`, and `{{= price * 2}}` is the same as `{{mul price 2}}`.

`+` adds numbers, including text that holds a number, such as an attribute set to `"5"` from a text input. If either value is other text, it joins them instead, so `name + " the Brave"` gives "Bob the Brave". The other operators only work with numbers. An attribute that hasn't been set counts as `0`, or as empty text when joining.

Dividing by zero, or using `-`, `*`, `/` or `%` on something that isn't a number, shows an error in the story.

To round a result, or use the [other helpers for numbers](#maths-helpers) and [for text](#text-helpers), put the calculation in parentheses: `{{= (round (gold / 3))}}`. A helper's values are each a single value, so `(round gold / 3)` doesn't work.

### Choosing between two values

`condition ? value : other value` is the first value if the condition is true, and the other value if it isn't. It works anywhere a calculation does, unlike `{{#if}}...{{else}}...{{/if}}`, so you can use it in `@set` and inside a helper's values:

```squiffy
@set status = hp > 0 ? "alive" : "dead"
You are {{= hp > 0 ? "alive" : "dead"}}.
You have {{= gold}} {{= gold = 1 ? "coin" : "coins"}}.
{{= hp > 10 ? "well" : hp > 0 ? "hurt" : "dead"}}
```

The last one shows how to choose between more than two: `a ? b : c ? d : e` means `a ? b : (c ? d : e)`.

It's converted to the `cond` helper: `{{= hp > 0 ? "alive" : "dead"}}` is the same as `{{cond (gt hp 0) "alive" "dead"}}`. Both values are worked out before one is chosen, so a helper that changes something, such as `(pop "queue")`, does so whichever value is chosen.

### Understanding parentheses vs double brackets

When working with helpers, you'll encounter two different bracket types:

**Double brackets `{{}}` - Output values or call helpers:**
```squiffy
{{score}}                    - Display an attribute
{{set "score" 100}}          - Call a helper
{{#if has_key}}...{{/if}}    - Block helper
```

**Parentheses `()` - Subexpressions (helper arguments):**

When you need to pass the *result* of one helper as an argument to another helper, use parentheses:

```squiffy
{{#if (seen "intro")}}Welcome back{{/if}}
{{random (array "red" "green" "blue")}}
{{#if (length "inventory") > 3}}Your bag is getting heavy{{/if}}
```

In these examples:
- `(seen "intro")` - The `seen` helper returns true/false, which becomes the condition for `if`
- `(array "red" "green" "blue")` - The `array` helper creates an array, which is passed to `random`
- `(length "inventory")` - The `length` helper returns a number, which is compared with 3

**Why not `{{#if {{seen ...}}}}`?**

You cannot nest `{{}}` inside `{{}}` - that's invalid Handlebars syntax. Use parentheses for subexpressions:

```squiffy
❌ Wrong:  {{#if {{seen "intro"}}}}...{{/if}}
✅ Right:  {{#if (seen "intro")}}...{{/if}}

❌ Wrong:  {{random {{array "a" "b" "c"}}}}
✅ Right:  {{random (array "a" "b" "c")}}
```

**Nesting subexpressions:**

You can nest parentheses to combine multiple helpers:

```squiffy
{{set "next_round" (random (array "music" "sport" "history"))}}
```

Here, `(array "music" "sport" "history")` is evaluated first, then its result is passed to `random`, and finally the result of `random` is passed to `set`.

<Aside type="tip">
**Quick rule:** Use `{{}}` to call a helper directly. Use `()` when a helper's result needs to be passed to another helper.
</Aside>

## Attribute helpers

See [Attributes](/attributes/) for detailed documentation and examples.

### Reading attributes

| Helper | Description | Example |
|--------|-------------|---------|
| `{{attribute}}` | Display attribute value (single-word names, always gets latest value) | `{{score}}` |
| `{{get "name"}}` | Get attribute value (for multi-word names or dynamic attribute names from expressions) | `{{get "player name"}}` |

### Modifying attributes

| Helper | Parameters | Description | Example |
|--------|------------|-------------|---------|
| `{{set}}` | `"attribute" value` | Set attribute to a value, which can be a [calculation](#calculations) | `{{set "score" 100}}` or `{{set "score" score * 2}}` |
| `{{unset}}` | `"attribute"` | Set attribute to false | `{{unset "has_key"}}` |
| `{{inc}}` | `"attribute" [amount]` | Increment by 1 or specified amount | `{{inc "score"}}` or `{{inc "score" bonus * 10}}` |
| `{{dec}}` | `"attribute" [amount]` | Decrement by 1 or specified amount | `{{dec "health"}}` or `{{dec "health" damage - armour}}` |
| `{{forget}}` | `["attribute" ...]` | Clear the [attributes that last between playthroughs](/attributes/#attributes-that-last-between-playthroughs): all of them, or the ones named | `{{forget}}` or `{{forget "endings"}}` |

<Aside>
These helpers execute at render time and respect `{{#if}}` conditions, unlike `@set`, `@inc`, `@dec`, and `@unset` directives which always execute when a section/passage loads.
</Aside>

## Comparison helpers

See [Attributes](/attributes/#comparing-attributes) for examples. In `{{#if}}` and `{{#unless}}`, you can use the operator instead (see [Conditions](#conditions)).

| Helper | Description | Operator | Example |
|--------|-------------|----------|---------|
| `{{eq a b}}` | Returns true if a equals b | `a = b` | `{{#if status = "complete"}}Done{{/if}}` |
| `{{ne a b}}` | Returns true if a not equals b | `a != b` | `{{#if health != 0}}Still alive{{/if}}` |
| `{{gt a b}}` | Returns true if `a > b` | `a > b` | `{{#if score > 100}}High score!{{/if}}` |
| `{{gte a b}}` | Returns true if `a >= b` | `a >= b` | `{{#if level >= 5}}Advanced{{/if}}` |
| `{{lt a b}}` | Returns true if `a < b` | `a < b` | `{{#if health < 20}}Low health{{/if}}` |
| `{{lte a b}}` | Returns true if `a <= b` | `a <= b` | `{{#if age <= 18}}Minor{{/if}}` |

## Logic helpers

See [Attributes](/attributes/#logic-helpers) for examples. In `{{#if}}` and `{{#unless}}`, you can use the operator instead (see [Conditions](#conditions)).

| Helper | Description | Operator | Example |
|--------|-------------|----------|---------|
| `{{and ...}}` | Returns true if all arguments are truthy | `a and b` | `{{#if has_key and door_locked}}Can unlock{{/if}}` |
| `{{or ...}}` | Returns true if any argument is truthy | `a or b` | `{{#if is_admin or is_moderator}}Has powers{{/if}}` |
| `{{not value}}` | Negates a boolean value | `not a` | `{{#if not game_over}}Continue{{/if}}` |

## Maths helpers

You can usually use the operator instead (see [Calculations](#calculations)). Each helper takes exactly two values.

| Helper | Description | Operator | Example |
|--------|-------------|----------|---------|
| `{{add a b}}` | Adds two numbers, or joins them if either is other text | `a + b` | `{{set "total" (add price tax)}}` |
| `{{sub a b}}` | Subtracts b from a | `a - b` | `{{set "left" (sub total spent)}}` |
| `{{mul a b}}` | Multiplies a by b | `a * b` | `{{set "gold" (mul gold 2)}}` |
| `{{div a b}}` | Divides a by b | `a / b` | `{{set "share" (div gold players)}}` |
| `{{mod a b}}` | The remainder after dividing a by b | `a % b` | `{{#if (mod turn 2) = 0}}Even turn{{/if}}` |

These work out a number from others. Like the helpers above, they take numbers or text that holds a number, and show an error for anything else. A calculation inside one needs `{{= }}` around it, as in the examples:

| Helper | Description | Example |
|--------|-------------|---------|
| `{{round a}}` | Rounds a to the nearest whole number. Halves round up, so 2.5 is 3 and -2.5 is -2 | `{{= (round (gold / 3))}}` |
| `{{round a places}}` | Rounds a to that many decimal places | `{{round price 2}}` |
| `{{floor a}}` | Rounds a down to a whole number | `{{= (floor (gold / 3))}}` |
| `{{ceil a}}` | Rounds a up to a whole number | `{{= (ceil (distance / speed))}}` |
| `{{abs a}}` | a without its minus sign, so -3 is 3 | `{{= (abs (x - target))}}` |
| `{{min a b ...}}` | The smallest of the numbers, or of the numbers in an array | `{{set "hp" (min (hp + 5) max_hp)}}` |
| `{{max a b ...}}` | The largest of the numbers, or of the numbers in an array | `{{max scores}}` |

## Text helpers

| Helper | Description | Example |
|--------|-------------|---------|
| `{{upper text}}` | The text in capitals | `{{upper name}}` |
| `{{lower text}}` | The text in small letters | `{{#if (lower answer) = "yes"}}` |
| `{{capitalise text}}` | The text with a capital first letter. `capitalize` works too | `{{capitalise weapon}} in hand, you step forward.` |

An attribute that hasn't been set is empty text, and a number is turned into text.

To check whether some text has other text in it, use `contains`. It tells capitals from small letters, so use `lower` on both to ignore them:

```squiffy
{{#if name contains "Mac"}}A Scottish name!{{/if}}
{{#if (lower answer) contains "yes"}}Glad to hear it.{{/if}}
```

`.length` is the number of letters, e.g. `{{#if name.length > 10}}That's a long name.{{/if}}`.

## Navigation helpers

See [Attributes](/attributes/#tracking-sections-and-passages) for examples.

| Helper | Parameters | Description | Example |
|--------|------------|-------------|---------|
| `{{seen}}` | `"name"` | Check if section/passage has been visited | `{{#if (seen "intro")}}Welcome back{{/if}}` |
| `{{visits}}` | `"name"` | The number of times a section or passage has been visited, or 0 | `{{#if (visits "cave") > 2}}You know this cave well{{/if}}` |
| `{{at}}` | `"name"` or `(array ...)` | Check if currently at a specific section | `{{#if (at "ending")}}Game over{{/if}}` |
| `{{goto}}` | `"name" [after=milliseconds]` | Go to a section once this one has been shown, or after a delay: milliseconds, a time like `"3s"`, or an expression. See [Go to another section](/basic-concepts/#go-to-another-section) | `{{#if health <= 0}}{{goto "death"}}{{/if}}` |
| `{{#once}}...{{else}}...{{/once}}` | `["name"]` | Show the text inside the first time it's shown, and the `{{else}}` text (or nothing) after that. Each one remembers for itself; ones with the same name share their memory. `{{#firsttime}}` is another name for it. See [The first time](/dynamic-text/#the-first-time) | `{{#once}}A bat flies out!{{else}}It's quiet.{{/once}}` |
| `{{#every}}` | `milliseconds [times=n] [append=true]` | Show the text inside again and again while the player is in the section. See [Repeating text](/dynamic-text/#repeating-text) | `{{#every 1000}}{{dec "fuse"}}{{fuse}}...{{/every}}` |
| `{{clear}}` | | Clear the screen, like `@clear`, but only if the text reaches it, so it can go in an `{{#if}}`. What came before it in this section or passage goes too. See [Clear the screen](/basic-concepts/#clear-the-screen) | `{{#if previous_section != "change"}}{{clear}}{{/if}}` |
| `{{stop}}` | | Inside `{{#every}}`, stop showing its text after this time | `{{#if fuse <= 0}}{{stop}}{{/if}}` |
| `{{deactivate}}` | `"name" ["name"...]`, or nothing for this passage | Turn off the links to passages in this section. See [Turning off passage links](/basic-concepts/#turning-off-passage-links) | `{{#if talks > 2}}{{deactivate}}{{/if}}` |

## Listing sections and passages

See [Listing passages, and tagging them](/basic-concepts/#listing-passages-and-tagging-them) for examples. Each one gives a list, for `{{#each}}`, `join`, `random` and the other [array helpers](#array-management-helpers).

| Helper | Parameters | Description | Example |
|--------|------------|-------------|---------|
| `passages` | `["section"] [tagged="..."] [untagged="..."]` | The names of a section's passages, in the order they're written: this section's and the master section's if no section is given, and the master section's for `""`. The master passage, `@1`, `@last` and `@after` aren't listed. `tagged` lists only those with all these `@tag` tags, and `untagged` leaves out those with any of them | `{{#each (passages tagged="passenger")}}{{passage this}} {{/each}}` |
| `sections` | `[tagged="..."] [untagged="..."]` | The names of the story's sections, apart from the master section | `{{random (sections tagged="dream")}}` |
| `tags` | `["name"]` | A passage's or section's `@tag` tags, or this section's | `{{#if (tags "a busker") contains "settled"}}` |

With nothing after them, `{{passages}}`, `{{sections}}` and `{{tags}}` still show an attribute with that name, if there is one.

## Link helpers

See [Attributes](/attributes/#creating-links-with-helpers) for examples.

| Helper | Parameters | Description |
|--------|------------|-------------|
| `{{section}}` | `"name" [text="..."] [set="..."]` | Create a section link with optional custom text and attribute changes |
| `{{passage}}` | `"name" [text="..."] [set="..."]` | Create a passage link with optional custom text and attribute changes |
| `{{restart}}` | `[text="..."] [confirm=false]` | A link that restarts the story, like the Restart button. It asks the player first, unless `confirm=false`. See [Restarting and saving from the story](/basic-concepts/#restarting-and-saving-from-the-story) |
| `{{saves}}` | `[text="..."]` | A link that opens the Saved games dialog, like the Save button |
| `{{settings}}` | `[text="..."]` | A link that opens the Settings dialog, for a story with [player settings](/buttons-panels-settings/#player-settings) |

Example:
```squiffy
{{section "next_room" text="Enter" set="visited=true, count+=1, room='hall'"}}
```

`set` takes the same comma-separated assignments as a link, such as `[[Enter]](next_room, visited=true)`: see [Setting attributes](/attributes/#setting-attributes). Text in them goes in quotes, and single quotes save escaping the double quotes around `set`.

## Sound helpers

See [Music and sound](/images-and-files/#music-and-sound) for examples.

| Helper | Parameters | Description | Example |
|--------|------------|-------------|---------|
| `{{music}}` | `"file" [fade=seconds]` | Play music, which keeps playing from one section to the next until it's changed. The old music fades out and the new music fades in, over a second unless `fade=` says otherwise | `{{music "battle.mp3" fade=3}}` |

## Class helpers

These change the classes on the element that holds the story, for your [CSS](/styling/#changing-the-look-for-a-scene). Unlike the classes from `@class`, which change with the section, these stay until they're taken off. The Back button and saved games put them back as they were.

| Helper | Parameters | Description | Example |
|--------|------------|-------------|---------|
| `{{addclass}}` | `"class" ...` | Add classes | `{{addclass "dark"}}` |
| `{{removeclass}}` | `"class" ...` | Take classes off | `{{removeclass "dark"}}` |
| `{{toggleclass}}` | `"class" ...` | Add classes, or take them off if they're there | `{{toggleclass "big-text"}}` |
| `hasclass` | `"class" ...` | Whether the story has all these classes, from `@class` or `{{addclass}}` | `{{#if (hasclass "dark")}}` |

Each one takes one or more class names, which can be separate or in one piece of text with spaces between them: `{{addclass "dark" "rain"}}` and `{{addclass "dark rain"}}` are the same.

## Array management helpers

These helpers let you manage arrays stored in attributes - useful for tracking items, available options, or game state.

<Aside type="note">
The `"attribute"` parameter is the **name** of an attribute that stores an array (e.g., `"inventory"`). It must be a quoted string. The helper reads and modifies the array stored in that attribute. The helpers in [Joining, sorting and more](#joining-sorting-and-more) are different: they take the array itself, without quotes.
</Aside>

### Creating and modifying arrays

| Helper | Parameters | Description | Example |
|--------|------------|-------------|---------|
| `{{array}}` | `item1 item2 ...` | Create an array | `{{set "items" (array "a" "b" "c")}}` |
| `{{append}}` | `"attribute" value` | Append value to array stored in attribute | `{{append "inventory" "sword"}}` |
| `{{prepend}}` | `"attribute" value` | Prepend value to array stored in attribute | `{{prepend "queue" "urgent"}}` |
| `{{pop}}` | `"attribute"` | Remove and return first element from array | `{{set "next" (pop "queue")}}` |
| `{{remove}}` | `"attribute" value` | Remove first matching value from array | `{{remove "inventory" "key"}}` |

### Querying arrays

| Helper | Parameters | Description | Example |
|--------|------------|-------------|---------|
| `{{contains}}` | `"attribute" value` or `(array ...) value` | Check if array contains value | `{{#if (contains "inventory" "key")}}...{{/if}}` |
| `{{length}}` | `"attribute"` or `(array ...)` | Get number of elements in array | `{{length "inventory"}}` |

In a condition or calculation, you can also write `inventory contains "key"`, with the array itself rather than its name in quotes, and `inventory.length`. `contains` works on [objects](/attributes/#objects) too, where it's whether the object has a value with that name: `hero contains "hp"`, and so does `{{length}}`, which counts the values in it: `(length "hero")`.

### Joining, sorting and more

These helpers take the array itself, such as `inventory`, not its name in quotes. They don't change the attribute: they give you a new array or value, so to sort an array and keep it sorted, set it: `@set inventory = (sort inventory)`. Positions start at 0, as they do for `{{@index}}` and `inventory[0]`.

| Helper | Parameters | Description | Example |
|--------|------------|-------------|---------|
| `{{join}}` | `array`, and optionally `separator` and `last separator` | The items as text, with `", "` between them, or the separator you give. A last separator goes before the last item instead | `{{join inventory ", " " and "}}` gives "lamp, key and rope" |
| `{{sort}}` | `array` | The items in order: numbers first, smallest first, then text, alphabetically | `@set names = (sort names)` |
| `{{shuffle}}` | `array` | The items in a random order | `@set deck = (shuffle deck)` |
| `{{slice}}` | `array start`, or `array start end` | The items from position `start` up to, but not including, `end`, or to the end of the array. A negative position counts back from the end. Works on text too | `(slice inventory 0 3)` is the first three, `(slice inventory -2)` the last two |
| `{{first}}`, `{{last}}` | `array` | The first or last item, or nothing if the array is empty | `{{last visited}}` |
| `{{indexof}}` | `array value` | The position of the value in the array, or `-1` if it isn't there. Works on text too | `{{#if (indexof queue name) = 0}}You're next.{{/if}}` |
| `{{count}}` | `array value` | How many times the value is in the array, or some text is in other text | `You have {{count inventory "coin"}} coins.` |
| `{{range}}` | `from to` | The whole numbers from one number to the other, counting up or down | `(range 1 5)` is 1, 2, 3, 4, 5 |

To use an item at a position held in an attribute, put the attribute in square brackets: `{{= inventory[choice]}}`.

When each item needs a helper or a link, use `join` as a block, like `{{#each}}`. It shows its text for each item and puts the separators between them. Inside it, `{{this}}` is the item, and `{{@index}}`, `@first` and `@last` work as they do in `{{#each}}`. An `{{else}}` is shown if the array is empty:

<Sample script="@set ways = [&quot;north&quot;, &quot;south&quot;, &quot;east&quot;]
@set nothing = []
You can go {{#join ways &quot;, &quot; &quot; or &quot;}}[[{{this}}]](go, to = &quot;{{this}}&quot;){{/join}}.

You have {{#join nothing}}{{this}}{{else}}nothing{{/join}}.

[[go]]:
You go {{to}}."></Sample>

`{{#each}}` can go through any of these, so `range` repeats something a number of times, even a number worked out as the story runs. A calculation inside a helper goes in brackets of its own:

<Sample script="@set lives = 3
@set bag = [&quot;rope&quot;, &quot;lamp&quot;, &quot;key&quot;]
Lives: {{#each (range 1 lives)}}♥{{/each}}

You're carrying {{join (sort bag) &quot;, &quot; &quot; and &quot;}}.

Countdown: {{#each (range (lives + 2) 1)}}{{this}}... {{/each}}Go!"></Sample>

### Examples

**Track available game rounds:**
```squiffy
{{!-- Initialize available rounds --}}
{{set "rounds" (array "Quiz" "Challenge" "Bonus")}}

{{!-- Pick a random round --}}
{{set "current" (random rounds)}}
You're playing: {{current}}

{{!-- Remove it so it can't be picked again --}}
{{remove "rounds" current}}

{{!-- Check if more rounds remain --}}
{{#if (length "rounds") > 0}}
[[Play next round]]
{{else}}
[[Final round]]
{{/if}}
```

**Manage an inventory:**
```squiffy
{{set "inventory" (array)}}

[pick up sword]:
{{append "inventory" "sword"}}
You picked up the sword.

[use key]:
{{#if (contains "inventory" "key")}}
{{remove "inventory" "key"}}
You used the key.
{{else}}
You don't have a key.
{{/if}}
```

**Process a queue:**
```squiffy
{{set "tasks" (array "Task A" "Task B" "Task C")}}

[next task]:
{{#if (length "tasks") > 0}}
Now doing: {{pop "tasks"}}
{{else}}
All tasks complete!
{{/if}}
```

## Dynamic content helpers

See [Dynamic text](/dynamic-text/) for detailed documentation and examples.

### Random text

| Helper | Parameters | Description |
|--------|------------|-------------|
| `{{random}}` | `(array ...) [set="attribute"]` | Select a random item from an array, optionally storing the result |

Example:
```squiffy
The weather is {{random (array "sunny" "cloudy" "rainy") set="weather"}}.
```

### Animation

| Helper | Parameters | Description |
|--------|------------|-------------|
| `{{#animate}}...{{/animate}}` | `"effect" [trigger="link"] [style="..."] [loop=true]` | Animate text with visual effects |

Available effects:
- `typewriter` - Text appears character by character
- `toast` - Text slides in from bottom
- `fadeIn` - Text fades in
- `continue` - Clickable link that pauses animation queue

Example:
```squiffy
{{#animate "typewriter"}}This text appears gradually.{{/animate}}
```

### Styling text

| Helper | Parameters | Description |
|--------|------------|-------------|
| `{{#style}}...{{/style}}` | `"class" ...` | Give the text inside one or more classes, for your [CSS](/styling/#styling-some-text) or Squiffy's [text effects](/dynamic-text/#text-effects) |

The effects are `shake`, `shudder`, `rumble`, `sway`, `buoy`, `pulse`, `fade-in-out`, `blink`, `flicker`, `blur`, `blurrier`, `smear`, `mirror` and `upside-down`.

Example:
```squiffy
The sign says {{#style "warning"}}KEEP OUT{{/style}}, and the ground {{#style "rumble"}}shakes{{/style}}.
```

### Labels and replacement

| Helper | Parameters | Description |
|--------|------------|-------------|
| `{{#label}}...{{/label}}` | `"name"` | Create a labeled span that can be replaced later |
| `{{#replace}}...{{/replace}}` | `"label"` | Replace the content of a labeled span |

Example:
```squiffy
I bought {{#label "item"}}milk{{/label}}.

[change]:
{{#replace "item"}}bread{{/replace}}
```

### Rotating and sequence links

| Helper | Parameters | Description |
|--------|------------|-------------|
| `{{rotate}}` | `(array ...) [set="attribute"] [show="next"]` | Create a cycling link that rotates through options infinitely |
| `{{sequence}}` | `(array ...) [set="attribute"] [show="next"]` | Create a sequence link that disables after the last option |

Example:
```squiffy
Size: {{rotate (array "small" "medium" "large") set="size"}}
```

### Live updating

| Helper | Parameters | Description |
|--------|------------|-------------|
| `{{live}}` | `"attribute" [section="name"] [passage="name"]` | Display attribute value that updates automatically when the attribute changes |

Example:
```squiffy
Score: {{live "score"}}
```

The `section` and `passage` parameters let you display processed content from another section/passage that updates when the attribute changes:

```squiffy
{{live "category" section="categoryDescription"}}
```

## Standard Handlebars helpers

In addition to Squiffy's custom helpers, you have access to standard Handlebars block helpers:

| Helper | Description | Example |
|--------|-------------|---------|
| `{{#if}}...{{/if}}` | Conditional content | `{{#if has_key}}You have a key{{/if}}` |
| `{{#if}}...{{else}}...{{/if}}` | Conditional with fallback | `{{#if alive}}Living{{else}}Dead{{/if}}` |
| `{{#if}}...{{else if}}...{{/if}}` | Multiple conditions | `{{#if score > 100}}High{{else if score > 50}}Medium{{else}}Low{{/if}}` |
| `{{#unless}}...{{/unless}}` | Inverted conditional | `{{#unless game_over}}Keep playing{{/unless}}` |
| `{{#each}}...{{/each}}` | Repeat for each item in an array, as `{{this}}`. See [Going through an array](/attributes/#going-through-an-array) | `{{#each inventory}}[[Drop the {{this}}]](drop, item = "{{this}}"){{/each}}` |

## Helpers and directives

`{{set}}`, `{{inc}}`, `{{dec}}` and `{{unset}}` run at the point in the text where they appear, so they respect `{{#if}}`. The `@set`, `@inc`, `@dec` and `@unset` directives always run when a section or passage is shown. See [Conditional attribute changes](/attributes/#conditional-attribute-changes). It's the same for `{{music}}` and `{{sound}}`, and the `@music` and `@sound` directives, and for `{{clear}}` and `@clear`.

## Creating custom helpers

You can add your own helpers with JavaScript. See [Creating custom helpers](/javascript/#creating-custom-helpers).
