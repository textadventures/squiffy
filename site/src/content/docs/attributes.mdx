Attributes are variables that store information about your story's state. You can use them to track things like player choices, scores, inventory, character relationships, and any other data that changes as the story progresses.

## Setting attributes

### Using directives

The simplest way to set an attribute is using the `@set` directive:

```squiffy
@set score = 1000
@set player_name = "Alice"
```

Text goes in quotes, and numbers and `true` or `false` don't. The value can also be another attribute, or a calculation (see [Calculating values](#calculating-values)):

```squiffy
@set weapon = "sword"
@set best_score = score
@set gold = gold + price * 2
@set rich = gold > 100
```

The value works just like a condition in `{{#if}}`: a word on its own is an attribute, so `@set weapon = sword` would set `weapon` to the value of an attribute called `sword`, not to the text "sword".

<Aside>
Stories made with Squiffy 6 used different rules: text didn't need quotes, and another attribute was written as `@score`. See [Coming from Squiffy 6](/coming-from-squiffy-6/) for how a story is converted.
</Aside>

For boolean (true/false) values, to set as true:

```squiffy
@set has_key
```

and to set as false:

```squiffy
@set not has_key
```

or alternatively:

```squiffy
@unset has_key
```

For number values, you can increase or decrease by 1:

```squiffy
@inc score
@dec health
```

Or increase or decrease by other amounts:

```squiffy
@inc score 100
@dec health 5
```

<Sample script="@set score = 0
@set health = 100

Your initial stats:
- Score: {{score}}
- Health: {{health}}

Click some links: [collect coin], [collect treasure], [take damage]

[collect coin]:
@inc score 10

You found a coin! Score: {{score}}

[collect treasure]:
@inc score 50

You found treasure! Score: {{score}}

[take damage]:
@dec health 20

Ouch! Health: {{health}}"></Sample>

### Setting from links

You can set attribute values directly from section and passage links using a comma-separated list of assignments, which work the same way as `@set`:

<Sample script="Choose your character class:

[[Warrior]](game_start, class=&quot;warrior&quot;, strength=10, health=100)
[[Mage]](game_start, class=&quot;mage&quot;, intelligence=10, health=60)
[[Rogue]](game_start, class=&quot;rogue&quot;, dexterity=10, health=80)

[[game_start]]:
You are a {{class}}.

{{#if class = &quot;warrior&quot;}}
Strength: {{strength}}, Health: {{health}}
{{else if class = &quot;mage&quot;}}
Intelligence: {{intelligence}}, Health: {{health}}
{{else if class = &quot;rogue&quot;}}
Dexterity: {{dexterity}}, Health: {{health}}
{{/if}}"></Sample>

You can also use increment (`+=`) and decrement (`-=`) operators, and calculations, in link attributes:

<Sample script="@set coins = 10

You have {{coins}} coins.

What will you do? [[Buy apple]](shop, coins-=3) or [[Sell gem]](shop, coins+=5)?

[[shop]]:
You now have {{coins}} coins."></Sample>

### More ways to set values

These work both with `@set` and in links:

| Syntax | Meaning | Example |
|--------|---------|---------|
| `a = "text"` | Set to some text | `@set weapon = "sword"` |
| `a = b` | Copy the value of another attribute | `@set best_score = score` |
| `a = ...` | Set to the result of a calculation or comparison | `@set total = price * 2` |
| `a += n`, `a -= n` | Add or subtract a number (which can also be a calculation) | `@set coins += price` |
| `a *= n`, `a /= n` | Multiply or divide by a number | `@set score *= 2` |
| `a := text` | Set to some text, after processing any `{{...}}` in it | `@set greeting := Hello, {{name}}!` |

`+=`, `-=`, `*=` and `/=` only work on numbers. To add text to the end of some text, use `+`: `@set title = name + " the Brave"`.

In a link, the assignments are separated by commas, but a comma inside quotes is part of the text: `[[Say hello]](next, greeting = "Hello, friend", met = true)`. They can use brackets, as long as each `(` has a matching `)`: `[[Buy]](shop, gold -= (price - 1) * 2)`.

For example, this link copies the current score into `final_score` and doubles the bonus:

```squiffy
[[Finish]](ending, final_score=score, bonus*=2)
```

### Conditional attribute changes

The `@set`, `@inc`, `@dec`, and `@unset` directives run when a section or passage loads—they always execute regardless of any `{{#if}}` conditions in the text.

If you want to change an attribute **conditionally** (only when an `{{#if}}` condition is true), use the helper versions instead:

```squiffy
{{#if (seen "helped the wizard")}}
{{inc "reputation"}}
The wizard remembers your kindness.
{{else}}
The wizard eyes you suspiciously.
{{/if}}
```

The available helpers are:

- `{{set "attribute" value}}` — set an attribute to a value
- `{{set "attribute" a + b * 2}}` — set an attribute to the result of a calculation (see [Calculating values](#calculating-values))
- `{{unset "attribute"}}` — set an attribute to false
- `{{inc "attribute"}}` — increase a number attribute by 1
- `{{inc "attribute" 5}}` — increase by a specific amount, which can also be a calculation
- `{{dec "attribute"}}` — decrease by 1
- `{{dec "attribute" 3}}` — decrease by a specific amount

These helpers produce no visible output—they only modify the attribute. The key difference from the `@` directives is that they execute at render time, so they respect `{{#if}}` conditions.

<Sample script="@set reputation = 0

Did you [help the old lady] cross the street?

Choose your next action: [Help someone] or [Ignore them]

[help the old lady]:
You helped an old lady cross the street earlier.

[Help someone]:
{{#if (seen &quot;help the old lady&quot;)}}
{{inc &quot;reputation&quot; 20}}
Your earlier kindness inspires you to help again!
{{else}}
{{inc &quot;reputation&quot; 5}}
You help someone.
{{/if}}

Reputation: {{reputation}}

[Ignore them]:
You walk past. Reputation: {{reputation}}"></Sample>

### Calculating values

`@set`, link assignments, `{{set}}`, `{{inc}}` and `{{dec}}` can work out a value using `+`, `-`, `*`, `/` and `%`, and `{{= ...}}` displays the result of a calculation:

<Sample script="@set gold = 10
@set price = 3

You have {{gold}} gold. A sword costs {{price}}, and a shield costs {{= price * 2}}.

[Sell your old armour]

[Sell your old armour]:
@set gold = gold + price * 2
You sell it for twice the price of a sword. You now have {{gold}} gold."></Sample>

`+` joins text too, so `{{set "title" name + " the Brave"}}` works. See [Calculations](/helpers-reference/#calculations) in the helpers reference for the details, including how `-` and `/` need spaces around them.

## Reading attributes

You can display the value of an attribute using `{{name}}` (if the attribute name is all one word), or `{{get "attribute name"}}` for multi-word attributes or when the attribute name comes from an expression.

```squiffy
You chose the {{weapon}}.
Your full name is {{get "player name"}}.
```

Both `{{attribute}}` and `{{get "attribute"}}` always return the latest value, even if the attribute was just modified by a helper in the same section.

<Sample script="@set player_name = &quot;Alice&quot;
@set favorite_color = &quot;blue&quot;

Hello, {{player_name}}!

Your favorite color is {{favorite_color}}."></Sample>

The main use for `{{get}}` is when you need to read an attribute whose name is stored in another variable. This enables dynamic attribute lookup:

<Sample script="@set room = &quot;kitchen&quot;
@set kitchen = &quot;A cozy room with a stove.&quot;
@set garden = &quot;A sunny outdoor space.&quot;

You are in the {{room}}.

{{get room}}

[[Go to the garden]](garden)

[[garden]]:
@set room = &quot;garden&quot;
You are now in the {{room}}.

{{get room}}"></Sample>

In this example, `{{get room}}` looks up the value of `room` (e.g., "kitchen"), then uses that as the name of another attribute to retrieve (getting the description stored in the `kitchen` attribute).

You can also read a value using [JavaScript](/javascript/#reading-and-setting-attributes):

```javascript
    var weapon = squiffy.get("weapon");
```

## Comparing attributes

You can compare attribute values in `{{#if}}` and `{{#unless}}` conditions. See [Conditions](/helpers-reference/#conditions) for the full list of operators.

### Equality comparisons

Use `=` to check if two values are equal, and `!=` to check if they're not equal:

<Sample script="@set choice = &quot;red&quot;

You chose {{choice}}.

{{#if choice = &quot;red&quot;}}
Red is a bold choice!
{{else if choice = &quot;blue&quot;}}
Blue is a calm choice.
{{else}}
An interesting choice!
{{/if}}"></Sample>

### Numeric comparisons

For number values, you can use:

- `a > b` — greater than
- `a >= b` — greater than or equal
- `a < b` — less than
- `a <= b` — less than or equal

You can calculate the values you compare, e.g. `{{#if gold >= price * 2}}`. See [Calculating values](#calculating-values).

<Sample script="@set score = 75

Your score is {{score}}.

{{#if score >= 90}}
Excellent work! You got an A.
{{else if score >= 80}}
Great job! You got a B.
{{else if score >= 70}}
Good work! You got a C.
{{else if score >= 60}}
You passed with a D.
{{else}}
You need to study more.
{{/if}}"></Sample>

### Logic helpers

You can combine conditions using `and`, `or` and `not`:

- `a and b` — true if both are true
- `a or b` — true if either is true
- `not a` — true if `a` is not true

<Sample script="@set has_key = true
@set has_map = true
@set door_locked = true

{{#if has_key and door_locked}}
You use the key to unlock the door.
{{else if door_locked}}
The door is locked. You need a key.
{{else}}
The door is already open.
{{/if}}

{{#if has_key and has_map}}
With both the key and the map, you're ready for adventure!
{{/if}}"></Sample>

Each of these operators has an equivalent helper (`eq`, `ne`, `gt`, `gte`, `lt`, `lte`, `and`, `or`, `not`), which you can use anywhere, not just in conditions. For example, `{{#if has_key and door_locked}}` is the same as `{{#if (and has_key door_locked)}}`. See the [Helpers reference](/helpers-reference/) for details.

## Tracking sections and passages

### The `{{seen}}` helper

You can check if the player has visited a section or passage using the `{{seen}}` helper. In this example, try clicking "cupboard" first to see the description of the closed cupboard. Then restart, and click "open" before "cupboard" to see the difference.

<Sample script="You can see a [cupboard]. Maybe you should [open] it?

[open]:
You open the cupboard.

[cupboard]:
The cupboard is
{{#if (seen &quot;open&quot;)}}
open, and there are empty bottles inside.
{{else}}
closed.
{{/if}}"></Sample>

You can also use JavaScript:

```javascript
    if (squiffy.story.seen("passage3")) {
        alert("You have seen passage3!");
    }
```

Sections and passages are looked up by name, so if two sections each have a passage with the same name, `{{seen}}` can't tell them apart. If that matters, give the passages different names.

### The `{{visits}}` helper

`{{visits}}` says how many times the player has visited a section or passage, or 0 if they haven't. Use it to show something different each time, or in a condition with `>`, `<` and the other comparison operators. Try going into the cave a few times:

<Sample script="[[start]]:
You're outside a cave. [[Go in]](cave)

[[cave]]:
{{#if (visits &quot;cave&quot;) = 1}}
It's dark inside. You can't see a thing.
{{else if (visits &quot;cave&quot;) < 4}}
You've been here before. Your eyes adjust to the gloom.
{{else}}
You know this cave like the back of your hand. You've been here {{visits &quot;cave&quot;}} times.
{{/if}}

[[Go back outside]](start)"></Sample>

`{{seen "cave"}}` is the same as `(visits "cave") > 0`. Like `{{seen}}`, `{{visits}}` counts a section reached with [`{{goto}}`](/basic-concepts/#go-to-another-section) or `squiffy.story.go`, and going back with the Back button takes the visit away again.

In JavaScript, use `squiffy.story.visits("cave")`.

### Counting turns

Squiffy keeps the number of section and passage links the player has clicked in the whole story so far in the `turns` attribute, starting at 0. Use it for time limits, or anything that should change as the story goes on:

<Sample script="The candle is burning down. [Read the letter], [look out of the window], or [[leave]].

[Read the letter]:
{{#if turns > 2}}It's too dark to read now.{{else}}The letter is from your sister.{{/if}}

[look out of the window]:
It's raining.

[[leave]]:
You left after {{turns}} turns."></Sample>

Following a [`{{goto}}`](/basic-concepts/#go-to-another-section) isn't a turn, as the player didn't click anything, and going back with the Back button takes the turn away again.

Squiffy sets `turns` itself, so don't set it in your story: the editor underlines it if you do.

This is different from [turn counting within a section](/basic-concepts/#running-a-passage-after-some-clicks), which counts passage clicks in the current section only, and starts again in each new section.

### Where the player came from

Squiffy keeps track of where the player was before they got to where they are now, in two attributes:

- `previous_section` is the section the player was in before this one.
- `previous` is the section or passage the player saw just before this one. In a section, that's the passage they clicked last in the section before, if they clicked one, or the section itself if they didn't.

Use them to write the way in to a section differently depending on where the player came from. Try going to the cave from the river, then start again and go from the forest:

<Sample script="[[start]]:
You can go to the [[river]] or the [[forest]].

[[river]]:
The water is cold. You can [look around], or follow the river to the [[cave]].

[look around]:
There's nothing here but rocks.

[[forest]]:
The trees are dense. A path leads to a [[cave]].

[[cave]]:
{{#if previous_section = &quot;river&quot;}}
You wade out of the river into the mouth of a cave.
{{else}}
You step out of the trees into the mouth of a cave.
{{/if}}

You were last in the {{previous_section}}, and the last thing you saw was &quot;{{previous}}&quot;."></Sample>

At the start of the story, both are empty. A section reached with [`{{goto}}`](/basic-concepts/#go-to-another-section) has the section the `{{goto}}` was in as its `previous_section`, and going back with the Back button puts both back to what they were.

Squiffy sets `previous` and `previous_section` itself, so don't set them in your story: the editor underlines them if you do.

### The `{{at}}` helper

The `{{at}}` helper checks if you're currently at a specific section. It can take a single section name or an array of section names.

This helper is particularly useful in master sections or passages (see [Master sections and passages](/basic-concepts/#master-sections-and-passages)), where you want to display different content depending on which section the player is in. It can also be useful when embedding text from another section.

<Sample script="[[section1]]:
This is section 1.

{{#if (at &quot;section1&quot;)}}
You are currently in section 1.
{{/if}}

[[Continue to section 2]](section2)

[[section2]]:
This is section 2.

{{#if (at (array &quot;section1&quot; &quot;section2&quot;))}}
You are in section 1 or section 2.
{{/if}}"></Sample>

## Creating links with helpers

In addition to the standard link syntax, you can create links programmatically using the `{{section}}` and `{{passage}}` helpers.

### The `{{section}}` helper

Creates a link to a section with optional custom text and attribute settings:

```squiffy
{{section "section_name" text="Link text" set="attribute='value', count+=1"}}
```

### The `{{passage}}` helper

Creates a link to a passage with optional custom text and attribute settings:

```squiffy
{{passage "passage_name" text="Link text" set="visited=true"}}
```

<Sample script="Choose your reward:

{{section &quot;reward&quot; text=&quot;Gold&quot; set=&quot;choice='gold', coins+=100&quot;}},
{{section &quot;reward&quot; text=&quot;Silver&quot; set=&quot;choice='silver', coins+=50&quot;}}, or
{{section &quot;reward&quot; text=&quot;Bronze&quot; set=&quot;choice='bronze', coins+=25&quot;}}

[[reward]]:
You chose {{choice}} and received {{coins}} coins!"></Sample>

## Interactive example: Food menu

Here's a complete example showing how attributes can work together to create a food ordering system:

<Sample script="@set total_cost = 0

**Restaurant Menu**

Please select your meal:

**Main Course:**
- [[Chicken Curry ($12)]](add_drink, main=&quot;Chicken Curry&quot;, cost=12)
- [[Vegetable Stir-Fry ($10)]](add_drink, main=&quot;Vegetable Stir-Fry&quot;, cost=10)
- [[Beef Burger ($14)]](add_drink, main=&quot;Beef Burger&quot;, cost=14)

[[add_drink]]:
{{set &quot;total_cost&quot; cost}}
You ordered: **{{main}}** - ${{cost}}

**Add a drink?**
- [[Soda ($3)]](add_dessert, drink=&quot;Soda&quot;, drink_cost=3)
- [[Juice ($4)]](add_dessert, drink=&quot;Juice&quot;, drink_cost=4)
- [[Water (free)]](add_dessert, drink=&quot;Water&quot;, drink_cost=0)
- [[No thanks]](add_dessert)

[[add_dessert]]:
{{#if drink}}{{inc &quot;total_cost&quot; drink_cost}}You added: {{drink}} {{#if drink_cost > 0}}(${{drink_cost}}){{else}}(free!){{/if}}{{/if}}

**Add a dessert?**
- [[Ice Cream ($6)]](finish, dessert=&quot;Ice Cream&quot;, dessert_cost=6)
- [[Cake ($7)]](finish, dessert=&quot;Cake&quot;, dessert_cost=7)
- [[Fruit ($4)]](finish, dessert=&quot;Fruit&quot;, dessert_cost=4)
- [[No thanks]](finish)

[[finish]]:
{{#if dessert}}{{inc &quot;total_cost&quot; dessert_cost}}You added: {{dessert}} (${{dessert_cost}}){{/if}}

- Main: {{main}} (${{cost}})
{{#if drink}}- Drink: {{drink}} {{#if drink_cost > 0}}(${{drink_cost}}){{else}}(free){{/if}}{{/if}}

**Total: ${{total_cost}}**

{{else if total_cost >= 15}}

{{else}}

{{/if}}"></Sample>

## Advanced: Arrays and complex data

You can use the `{{array}}` helper to create arrays for use with other helpers like `{{random}}`, `{{rotate}}`, and `{{at}}`:

```squiffy
{{random (array "option1" "option2" "option3")}}
{{at (array "section1" "section2" "section3")}}
```

In an expression, such as in `@set`, you can also write an array in square brackets:

```squiffy
@set fruits = ["apple", "pear", "plum"]
```

If an attribute holds an array, you can get one of its elements by its position in square brackets. Positions start at 0, so this shows the second element:

```squiffy
The second fruit is {{= fruits[1]}}.
```

The position can be another attribute, or a calculation, such as `fruits[choice]` or `fruits[choice + 1]`. Handlebars' own `{{fruits.[1]}}` works too.

See [Dynamic text](/dynamic-text/) for more information on using arrays with dynamic content helpers.

### Going through an array

`{{#each}}` repeats some text for each item in an array, with the item as `{{this}}`. Inside it, you can use the story's attributes, conditions and links as usual, and a link's text and assignments can use `{{this}}` too, so you can make a link for each item:

<Sample script="@set gold = 10
{{set &quot;stock&quot; (array &quot;apple&quot; &quot;loaf&quot; &quot;cheese&quot;)}}
You arrive at the market. [[Look at the stall]](stall)

[[stall]]:
You have {{gold}} gold. The stall has:

{{#each stock}}
- [[Buy the {{this}}]](bought, item = &quot;{{this}}&quot;, gold -= 2)
{{else}}
Nothing. You've bought it all!
{{/each}}

[[bought]]:
{{remove &quot;stock&quot; item}}
You buy the {{item}}. [[Back to the stall]](stall)"></Sample>

- The `{{else}}` part is shown when the array is empty.
- `{{@index}}` is the item's position, starting at 0, and `@first` and `@last` are true for the first and last items. For example, `{{#each stock}}{{#unless @first}}, {{/unless}}{{this}}{{/each}}` puts a comma between the items.
- To repeat something a number of times, go through a [`range`](/helpers-reference/#joining-sorting-and-more) of numbers: `{{#each (range 1 lives)}}♥{{/each}}`. You can go through a sorted or shuffled array, or part of one, in the same way: `{{#each (sort stock)}}`.
- In a link's assignments, put `{{this}}` in quotes, as in `item = "{{this}}"`. The assignments run when the player clicks the link, after the loop has finished, so `item = this` wouldn't work.
- A [passage](/basic-concepts/#passages) link in `{{#each}}` works on its own, like any other passage link. With `- [Examine the {{this}}](examine, item = "{{this}}")`, clicking one item's link turns off just that link, and the passage `[examine]` can say `It's a {{item}}.`, so the player can examine each item in turn.

### Objects

An attribute can hold an object: a set of values, each with a name. Write one in curly brackets, with a name and a value for each of its values, and get a value inside it with a dot:

<Sample script="@set hero = { name: &quot;Ann&quot;, hp: 10, gold: 5 }
{{hero.name}} has {{hero.hp}} HP.

[[Rest at the inn]](inn, hero.hp += 5, hero.gold -= 2)

[[inn]]:
{{hero.name}} wakes up with {{hero.hp}} HP and {{hero.gold}} gold.
{{#if hero.hp > 12}}She feels great.{{/if}}"></Sample>

- Set a value inside an object just as you would an attribute: `@set hero.hp = 10`, `@set hero.hp += 5`, `@set hero.poisoned`, and the same in a link. If the object isn't there yet, it's made, so `@set hero.hp = 10` works on its own.
- An object can hold other objects and arrays, as in `@set hero = { stats: { str: 3 }, items: ["lamp"] }`, with `hero.stats.str` for a value inside the one inside.
- A name that isn't a single word goes in quotes, both in the object and in square brackets when you use it: `{ "max hp": 12 }` and `hero["max hp"]`. Square brackets also take the name from another attribute, as in `hero[stat]`.
- `@set best = hero` copies the object, so changing `best` afterwards doesn't change `hero`.
- `{{set}}`, `{{inc}}`, `{{dec}}`, `{{unset}}`, `{{append}}` and the other helpers that change an attribute, and [`{{live}}`](/dynamic-text/#live), take a value inside an object too, as in `{{inc "hero.hp" 5}}` or `{{live "hero.hp"}}`. So does [`squiffy.get` and `squiffy.set`](/javascript/#reading-and-setting-attributes) in JavaScript.
- Going back and saved games keep objects, like any other attribute.

An array can hold objects, and `{{#each}}` goes through them, with each object's values as `{{this.name}}`, or just `{{name}}`. Square brackets pick one out, and the position can come from another attribute:

<Sample script="@set party = [{ name: &quot;Ann&quot;, hp: 10 }, { name: &quot;Bo&quot;, hp: 4 }]
@set leader = 0
{{#each party}}
- {{this.name}}: {{hp}} HP {{#if @index = leader}}(leader){{/if}}
{{/each}}

{{= party[leader].name}} leads the party. [[Make Bo the leader]](next, leader = 1, party[1].hp += 2)

[[next]]:
{{= party[leader].name}} leads the party now, with {{= party[leader].hp}} HP."></Sample>

To show a value from a position in an array, use `{{= }}`, as in `{{= party[leader].name}}`. A path with only names and dots, like `{{hero.hp}}`, doesn't need it.
