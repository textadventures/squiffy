## Conditions

Use `{{#if}}` to show text only when a condition is true, with `{{else}}` and `{{else if}}` for alternatives. `{{#unless}}` shows text when a condition is false.

<Sample script="@set score = 120
@set has_key = true

{{#if score > 100 and has_key}}
You have a high score and the key!
{{else if score > 100}}
You have a high score, but no key.
{{else}}
Keep playing.
{{/if}}"></Sample>

You can compare values with `=`, `!=`, `>`, `>=`, `<` and `<=`, combine conditions with `and`, `or` and `not`, and use parentheses to group them. You can also calculate with `+`, `-`, `*`, `/` and `%`, e.g. `{{#if gold >= price * 2}}`. See [Conditions](/helpers-reference/#conditions) in the helpers reference for details.

To display the result of a calculation, use `{{= ...}}`:

<Sample script="@set price = 3
@set quantity = 4

{{quantity}} apples at {{price}} each costs {{= price * quantity}}."></Sample>

## The first time

`{{#once}}` shows its text the first time it's shown, and never again. With an `{{else}}`, it shows that from the second time on.

<Sample script="[[cave]]:
You're in the cave. {{#once}}A bat flies out, right past your ear!{{else}}It's quiet now.{{/once}}

[[Go out and come back in]](cave)"></Sample>

Each `{{#once}}` remembers for itself, so you can have several in a section, and one in text that you [embed](/basic-concepts/#embed-text) in several places is still only shown the first time, wherever that is. Helpers inside it, such as `{{inc}}`, only run that first time too.

To have the same thing happen once across different places, give them the same name:

```squiffy
[[kitchen]]:
{{#once "smell"}}Something is burning.{{/once}}

[[hall]]:
{{#once "smell"}}Something is burning.{{/once}}
```

`{{#firsttime}}` is another name for `{{#once}}`. To check whether the player has been to a particular section or passage before, use [`seen` or `visits`](/attributes/#the-seen-helper) instead.

## Random

Use the `{{random}}` helper to insert random text. You can provide a list of options using the `array` function.
To store the result in an [attribute](/attributes/), use the `set` option.

<Sample script="It's another {{random (array &quot;Monday&quot; &quot;Tuesday&quot; &quot;Wednesday&quot; &quot;Thursday&quot; &quot;Friday&quot; &quot;Saturday&quot; &quot;Sunday&quot;)}} in the city.

The weather is {{random (array &quot;sunny&quot; &quot;cloudy&quot; &quot;rainy&quot; &quot;windy&quot; &quot;snowy&quot;) set=&quot;weather&quot;}}.

It feels like it's always {{weather}} here.

+++Continue...

The weather is still {{weather}}.
"></Sample>

## Text effects

`{{#style}}` gives some text an effect that lasts, unlike an animation, which plays once:

<Sample script="The ground {{#style &quot;rumble&quot;}}trembles{{/style}} beneath your feet. A voice {{#style &quot;fade-in-out&quot;}}whispers your name{{/style}}, and the room goes {{#style &quot;blur&quot;}}out of focus{{/style}}."></Sample>

| Effect | What it does |
|---|---|
| `shake` | Shakes from side to side |
| `shudder` | Trembles quickly from side to side |
| `rumble` | Trembles quickly up and down |
| `sway` | Rocks slowly from side to side |
| `buoy` | Bobs slowly up and down |
| `pulse` | Fades a little and back |
| `fade-in-out` | Fades away completely and back |
| `blink` | Blinks on and off |
| `flicker` | Flickers like a failing light |
| `blur`, `blurrier` | Out of focus |
| `smear` | Smudged to the right |
| `mirror` | Back to front |
| `upside-down` | Upside down |

You can give text more than one effect, and they all apply: `{{#style "rumble fade-in-out"}}` rumbles as it fades. You can add your own classes too: see [Styling some text](/styling/#styling-some-text). Effects that move stay still for readers who've asked their system to reduce motion.

### Animation options

You can change how an animation runs by adding options after its name:

| Option | Applies to | Description |
|--------|------------|-------------|
| `interval=n` | `typewriter`, `toast` | Milliseconds between each character (`typewriter`, default 100) or word (`toast`, default 200) appearing |
| `fadeDuration=n` | `typewriter`, `toast` | Milliseconds for each character or word to fade in (default 100) |
| `duration=n` | `fadeIn` | Milliseconds for the fade (default 500) |
| `start=n` | `typewriter`, `toast`, `fadeIn` | Milliseconds to wait before starting |
| `loop=true` | all except `continue` | Repeat the animation forever |
| `trigger="link"` | all except `continue` | Wait until a link inside the animated text is clicked, instead of running straight away |

Times can also be written in seconds, as text: `start="1.5s"` is the same as `start=1500`. They can come from an [expression](/attributes/#calculating-values) too, such as `start=delay * 1000`.

<Sample alwaysShowRestart={true} script="{{#animate &quot;typewriter&quot; interval=30}}This text types out quickly.{{/animate}}

{{#animate &quot;typewriter&quot; interval=300 start=1500}}This text waits, then types slowly.{{/animate}}

Click {{#animate &quot;fadeIn&quot; trigger=&quot;link&quot; loop=true}}[this link]{{/animate}} to make it pulse.

[this link]:
Clicked!
"></Sample>

### Click to continue

Animations are queued and play sequentially. Sometimes you want to pause the queue and let the reader control when to continue. The `continue` animation displays text as a clickable link that resumes the animation queue when clicked.

<Sample alwaysShowRestart={true} script="The door creaked open slowly...

{{#animate &quot;continue&quot;}}Step inside{{/animate}}

{{#animate &quot;fadeIn&quot;}}You enter a dark room. Shadows dance on the walls.{{/animate}}
"></Sample>

The `continue` animation supports different visual styles via the `style` parameter:

- `pulse` (default) - the text fades in and out
- `glow` - a pulsing blue glow effect
- `bounce` - subtle vertical bouncing
- `wave` - opacity ripples through each character

<Sample alwaysShowRestart={true} script="Choose your adventure...

{{#animate &quot;continue&quot; style=&quot;wave&quot;}}Enter the cave{{/animate}}

{{#animate &quot;typewriter&quot;}}You venture into the darkness...{{/animate}}
"></Sample>

## Transitions

`@transition` sets how a section or passage appears, such as fading in or sliding up:

<Sample alwaysShowRestart={true} script="@transition blur 2s
Everything is hazy. Somewhere, an alarm is ringing.

[[Wake up]](awake)

[[awake]]:
@transition slide-up 1s
You sit up in bed. It was only a dream."></Sample>

| Transition | How the text appears |
|---|---|
| `fade` | Fades in. `dissolve` is the same |
| `slide-up`, `slide-down`, `slide-left`, `slide-right` | Fades in as it moves up, down, left or right into place. With [`@leave`](#when-the-screen-is-cleared), it fades out moving the same way |
| `zoom` | Fades in as it grows to its full size |
| `blur` | Comes into focus |
| `pulse` | Fades in and swells a little |
| `rumble`, `shudder` | Fades in, shaking up and down, or from side to side |
| `flicker` | Flickers on |

Click each one to see it:

<Sample alwaysShowRestart={true} script="[fade], [slide-up], [slide-down], [slide-left], [slide-right], [zoom], [blur], [pulse], [rumble], [shudder], [flicker]

[fade]:
@transition fade 1s
Fading in.

[slide-up]:
@transition slide-up 1s
Sliding up.

[slide-down]:
@transition slide-down 1s
Sliding down.

[slide-left]:
@transition slide-left 1s
Sliding left.

[slide-right]:
@transition slide-right 1s
Sliding right.

[zoom]:
@transition zoom 1s
Zooming in.

[blur]:
@transition blur 1s
Coming into focus.

[pulse]:
@transition pulse 1s
Pulsing.

[rumble]:
@transition rumble 1s
Rumbling.

[shudder]:
@transition shudder 1s
Shuddering.

[flicker]:
@transition flicker 1s
Flickering on."></Sample>

A time after the name, such as `2s` or `400ms`, says how long it takes. Without one, it takes half a second.

A passage appears the way its section does, unless it has a `@transition` of its own. `@transition` in the [master section](/basic-concepts/#master-sections-and-passages) is for every section and passage, and `@transition none` turns it off for one of them.

Transitions only play when the text first appears: not when the player goes back, or loads a saved game. If the player has asked their system for less motion, every transition is a plain fade.

### When the screen is cleared

When a section or passage [clears the screen](/basic-concepts/#clear-the-screen), with `@clear` or `{{clear}}`, `@leave` says how the old text goes first. It takes the same transitions as `@transition`, played backwards, so `@leave fade` fades the old text out, and `@leave zoom` shrinks it away. A slide moves the way it's named, so `@leave slide-up` slides the old text up and away:

<Sample alwaysShowRestart={true} script="The lights flicker. [[Run]](corridor)

[[corridor]]:
@clear
@leave slide-up 1s
@transition fade 1s
You're in a long corridor, and the room behind you has gone. [[Keep running]](outside)

[[outside]]:
@clear
@leave blur 2s
You burst out into the daylight."></Sample>

With `@leave` and `@transition` both sliding the same way, each new screen follows the last one across, as if the story were moving on:

```squiffy
[[]]:
@clear
@leave slide-left
@transition slide-left
```

Here, each section's text slides off to the left, and the next one slides in from the right. The slides only move a little way, as they fade. To make them go all the way across, see [Transitions](/styling/#transitions) in Customising styles.

The player can't click anything until the old text has gone, so keep it short. As with `@transition`, a passage uses its section's `@leave` unless it has its own, `@leave` in the master section is for every section and passage that clears the screen, and `@leave none` turns it off. When the player goes back, the old text comes back as it was.

To change how a transition looks, or add your own, see [Transitions](/styling/#transitions) in Customising styles.

## Moving on after a delay

[`{{goto}}`](/basic-concepts/#go-to-another-section) with `after=` moves the story on to another section after a number of milliseconds, without the player clicking anything:

<Sample alwaysShowRestart={true} script="The lights flicker, and go out.
{{goto &quot;darkness&quot; after=3000}}

[[darkness]]:
@end
Something moves in the dark."></Sample>

If the player follows a link before the time is up, the story doesn't move on, so you can give them a limited time to act:

<Sample alwaysShowRestart={true} script="The floor starts to crumble. [[Jump!]](safe)
{{goto &quot;fall&quot; after=4000}}

[[safe]]:
@end
You make it to the other side.

[[fall]]:
@end
Too slow. You fall."></Sample>

The delay starts once the section has been written, so `{{goto}}` doesn't wait for an [animation](#animation) to finish. Add the animation's length to `after=` instead.

The delay can be worked out as the story runs, from an attribute or an [expression](/attributes/#calculating-values). It can also be text with a number of seconds, like `"3s"`, or milliseconds, like `"500ms"`:

<Sample alwaysShowRestart={true} script="@set fuse = 3
You light a fuse {{fuse}} seconds long. [[Run!]](safe)
{{goto &quot;boom&quot; after=fuse * 1000}}

[[safe]]:
@end
You dive behind a rock just in time.

[[boom]]:
@end
BOOM."></Sample>

## Repeating text

`{{#every}}` shows some text again and again while the player is in the section, every so many milliseconds. Each time, its text is worked out again and replaces what it showed before, so it can count down, or change with the story's attributes. It first shows its text after one wait:

<Sample alwaysShowRestart={true} script="@set fuse = 5
The fuse burns down: {{#every 1000}}{{dec &quot;fuse&quot;}}{{fuse}}...{{#if fuse <= 0}}{{stop}}{{goto &quot;boom&quot;}}{{/if}}{{/every}}

[[Run!]](safe)

[[safe]]:
@end
You dive behind a rock just in time.

[[boom]]:
@end
BOOM."></Sample>

It stops when:

- its text has a `{{stop}}` in it. The text is shown that time, and then no more.
- it has been shown `times=` times, as in `{{#every 1000 times=3}}`.
- the player moves on to another section. It keeps going while they click on passages in the section.

With `append=true`, each time its text is added after what it showed before, rather than replacing it:

<Sample alwaysShowRestart={true} script="Water drips from the ceiling. {{#every 800 append=true times=5}}Drip. {{/every}}"></Sample>

Like `after=`, the wait can be an expression, such as `{{#every delay * 1000}}`, or a time as text, such as `{{#every "1.5s"}}`.

Going back undoes what the text changed, along with everything else, and a saved game carries on where it was.

## Replace

By creating labels, you can replace existing output when a link is clicked or when a passage or section is displayed. In the example below, we create a label called "1" using `{{#label}}`, and in the next passage we replace the text inside that label:

<Sample script="I walked to the shops and I bought {{#label &quot;1&quot;}}a pint of milk{{/label}}.

Or maybe I bought [something different]?

[something different]:
{{#replace &quot;1&quot;}}a loaf of bread{{/replace}}"></Sample>

The replacement text can include links to other passages or sections:

<Sample script="I walked to the shops and I {{#label &quot;1&quot;}}bought a pint of milk{{/label}}.

But I was [thinking]...

[thinking]:
{{#replace &quot;1&quot;}}suddenly thought, hang on, I could [[go to the funfair]] or [[join the circus]] instead{{/replace}}

[[go to the funfair]]:
Off I went to the funfair...

[[join the circus]]:
Off I went to the circus..."></Sample>

## Rotate

For a text link that replaces itself each time it is clicked:

<Sample script="{{rotate (array &quot;one&quot; &quot;two&quot; &quot;three&quot;)}}"></Sample>

You can store the result in an [attribute](/attributes/):

<Sample script="Please choose: {{rotate (array &quot;small&quot; &quot;medium&quot; &quot;large&quot;) set=&quot;size&quot;}}

+++Then continue...

You chose {{size}}."></Sample>

You might want the link to display the _next_ option, rather than the current one. Use the `show="next"` option for this:

<Sample script="Current size: {{live &quot;size&quot;}}.

Change size: {{rotate (array &quot;small&quot; &quot;medium&quot; &quot;large&quot;) set=&quot;size&quot; show=&quot;next&quot;}}

+++Or pick this one...

You chose {{size}}."></Sample>

## Sequence

If you don't want a rotating list, use a sequence instead. The final option won't be a link.

<Sample script="{{sequence (array &quot;Ready&quot; &quot;Steady&quot; &quot;Go&quot;)}}"></Sample>

As a variation on this, you can use a section link as the final option in a sequence.

<Sample script="{{sequence (array &quot;Click me&quot; &quot;Click me again&quot; (section &quot;next&quot; text=&quot;And once more&quot;))}}

[[next]]:
Done!"></Sample>

## Live

Using `{{live}}`, you can change text that is already on-screen when an [attribute](/attributes/) value changes. It can show a value inside an [object](/attributes/#objects) too, as in `{{live "hero.hp"}}`.

In this example, notice how the static `{{count}}` does not change, but the live `{{live "count"}}` does as the `count` attribute is incremented.

<Sample script="@set count = 0

This is static: {{count}}.

This is live: {{live &quot;count&quot;}}.

+++Continue
@inc count

Now count is {{count}}.

+++Continue
@inc count

Now count is {{count}}."></Sample>

Here we combine `{{live}}` with `{{rotate}}` to create a button that cycles through options. Instead of simply
displaying the attribute value, we use the `section` parameter to display text which can itself contain
further helpers.

<Sample script="Choose a colour: {{rotate (array &quot;red&quot; &quot;green&quot; &quot;blue&quot;) set=&quot;colour&quot;}}

{{live &quot;colour&quot; section=&quot;colourDescription&quot;}}

[[colourDescription]]:
{{#if colour = &quot;red&quot;}}
The colour of fire and blood.
{{else if colour = &quot;green&quot;}}
The colour of nature and life.
{{else if colour = &quot;blue&quot;}}
The colour of the sky and the sea.
{{/if}}"></Sample>

With `section` or `passage`, the text is only shown again while the player is in the section with the `{{live}}` in it. Once they've moved on, it stays as it was, so the helpers in it don't run again.
