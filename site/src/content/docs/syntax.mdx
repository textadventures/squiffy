Everything you can write in a `.squiffy` file, in one place. Each row links to where it's explained in full.

## Sections and passages

| Write | What it does | See |
|---|---|---|
| `[[name]]:` | Starts a section called "name" | [Sections](/basic-concepts/#sections) |
| `[name]:` | Starts a passage called "name", in the section above it | [Passages](/basic-concepts/#passages) |
| `+++Continue...` | Ends this section with a link saying "Continue...", and starts a new section that it goes to | [Continue links](/basic-concepts/#continue-links) |
| `---` | Starts a new section with no name, for `[[text>]]` links to go to | [Section dividers](/basic-concepts/#section-dividers-and-next-section-links) |
| `[[]]:` | The master section: runs with every section | [Master sections](/basic-concepts/#master-sections-and-passages) |
| `[]:` | A master passage: runs with every passage in its section, or in every section if it's in the master section | [Master sections](/basic-concepts/#master-sections-and-passages) |
| `[@1]:`, `[@2]:`... | A passage that runs after the player has clicked that many passage links in the section | [Running a passage after some clicks](/basic-concepts/#running-a-passage-after-some-clicks) |
| `[@last]:` | A passage that runs once the player has clicked every passage link in the section | [Running a passage after some clicks](/basic-concepts/#running-a-passage-after-some-clicks) |
| `[@after]:` | A passage that runs after every passage link the player clicks in the section, or in every section if it's in the master section | [Running a passage after every click](/basic-concepts/#running-a-passage-after-every-click) |
| `[snippet: name]:` | A snippet for the editor's **Add** menu. It isn't part of the story | [Snippets](/snippets/#user-defined-snippets) |

Text before the first section is the start of the story, unless `@start` says otherwise. Section names must be unique in the story, and passage names in their section.

## Links

| Write | What it does | See |
|---|---|---|
| `[[cave]]` | A link to the section "cave", saying "cave" | [Sections](/basic-concepts/#sections) |
| `[[Go in]](cave)` | A link to the section "cave", saying "Go in" | [Sections](/basic-concepts/#sections) |
| `[look]` | A link to the passage "look" in this section | [Passages](/basic-concepts/#passages) |
| `[Look around](look)` | A link to the passage "look", saying "Look around" | [Passages](/basic-concepts/#passages) |
| `[[Go in]](cave, torch = true)` | A link that also sets attributes. Separate several with commas | [Setting from links](/attributes/#setting-from-links) |
| `[Take it](take, coins += 1)` | A passage link that sets attributes | [Setting from links](/attributes/#setting-from-links) |
| `[[Next>]]` | A link to the next section in the file | [Section dividers](/basic-concepts/#section-dividers-and-next-section-links) |
| `[[Next]](>, score = 10)` | A link to the next section that sets attributes | [Section dividers](/basic-concepts/#section-dividers-and-next-section-links) |
| `[a website](https://example.com)` | An ordinary web link, as in Markdown | [Basic concepts](/basic-concepts/) |
| `**[[cave]]**`, `[[**Go in**]](cave)`, `+++**Continue...**` | Bold links. Any Markdown or HTML works, around a link or inside its text, but only inside it when the link names where it goes | [Formatting links](/basic-concepts/#formatting-links) |

<Aside type="caution">
Any text in square brackets is a passage link, so `[like this]` in your story becomes a link to a passage called "like this". Links to web pages that start with `http://` or `https://`, and Markdown images, `![alt](cat.png)`, are left alone.
</Aside>

## Directives

Directives go on a line of their own. Those that change attributes run when their section or passage is shown, before its text.

| Write | What it does | See |
|---|---|---|
| `@title The Island` | The story's title, shown in the browser tab. Main file only | [Set the title](/basic-concepts/#set-the-title) |
| `@start cave` | Starts the story in the section "cave". Main file only | [Set the start section](/basic-concepts/#set-the-start-section) |
| `@set gold = 10` | Sets an attribute to a number | [Setting attributes](/attributes/#using-directives) |
| `@set name = "Alice"` | Sets an attribute to some text | [Setting attributes](/attributes/#using-directives) |
| `@set best = score` | Copies another attribute | [Setting attributes](/attributes/#using-directives) |
| `@set gold = gold + price * 2` | Sets an attribute to a calculation | [Calculating values](/attributes/#calculating-values) |
| `@set gold += 5` | Also `-=`, `*=` and `/=` | [More ways to set values](/attributes/#more-ways-to-set-values) |
| `@set greeting := Hello, {{name}}!` | Sets an attribute to text, after processing any `{{...}}` in it | [More ways to set values](/attributes/#more-ways-to-set-values) |
| `@set has_key` | Sets an attribute to `true` | [Setting attributes](/attributes/#using-directives) |
| `@set not has_key`, `@unset has_key` | Sets an attribute to `false` | [Setting attributes](/attributes/#using-directives) |
| `@inc score`, `@dec health` | Adds or takes away 1 | [Setting attributes](/attributes/#using-directives) |
| `@inc score 10`, `@dec health 5` | Adds or takes away a whole number. For a calculation, use `@set score += ...` | [Setting attributes](/attributes/#using-directives) |
| `@clear` | Clears the screen before showing this section or passage | [Clear the screen](/basic-concepts/#clear-the-screen) |
| `@repeat` | Lets the player click this passage's links again | [Passages you can click again](/basic-concepts/#passages-you-can-click-again) |
| `@end` | Marks the section as one of the story's endings | [Endings](/basic-concepts/#endings) |
| `@class dark cave` | Puts classes on the story while this section is the current one, for your CSS | [Changing the look for a scene](/styling/#changing-the-look-for-a-scene) |
| `@transition fade`, `@transition slide-up 1s` | How this section or passage appears, and how long that takes | [Transitions](/dynamic-text/#transitions) |
| `@leave fade`, `@leave slide-up 1s` | How the old text goes when this section or passage clears the screen | [When the screen is cleared](/dynamic-text/#when-the-screen-is-cleared) |
| `@music theme.mp3` | Plays music, which keeps playing from one section to the next until it's changed | [Music and sound](/images-and-files/#music-and-sound) |
| `@music stop` | Stops the music | [Music and sound](/images-and-files/#music-and-sound) |
| `@sound door.mp3` | Plays a sound once | [Music and sound](/images-and-files/#music-and-sound) |
| `@sound stop` | Stops the sounds playing once | [Music and sound](/images-and-files/#music-and-sound) |
| `@import chapter2.squiffy` | Adds another file to the story. Wildcards work: `@import *.squiffy` | [Importing files](/multiple-files/#importing-files) |
| `@import style.css`, `@import script.js` | Adds a stylesheet or script to the page | [Importing files](/multiple-files/#importing-files) |
| `@ui`, then `---` | A block of JavaScript, indented, that runs once when the story starts | [Running code when the story starts](/javascript/#running-code-when-the-story-starts) |
| `@ui helpers.js` | Runs a JavaScript file when the story starts | [Running code when the story starts](/javascript/#running-code-when-the-story-starts) |

## JavaScript

Lines indented with four spaces or a tab, at the start of a section or passage, are JavaScript, which runs when it's shown. An indented line after some text is text. See [JavaScript](/javascript/).

```squiffy
[[cave]]:
    squiffy.set("visited_cave", true);
You go into the cave.
```

## The text processor

Anything in `{{double curly brackets}}` is worked out as the text is shown. See [Dynamic text](/dynamic-text/) and the [Helpers reference](/helpers-reference/).

| Write | What it does | See |
|---|---|---|
| `{{score}}` | Shows an attribute | [Reading attributes](/attributes/#reading-attributes) |
| `{{get "player name"}}` | Shows an attribute whose name has spaces, or is in another attribute | [Reading attributes](/attributes/#reading-attributes) |
| `{{= price * 2}}` | Shows a calculation | [Calculating values](/attributes/#calculating-values) |
| `{{#if gold > 5}}...{{/if}}` | Shows text only if a condition is true | [Conditions](/dynamic-text/#conditions) |
| `{{else if gold > 2}}`, `{{else}}` | Other choices inside `{{#if}}` | [Conditions](/dynamic-text/#conditions) |
| `{{#unless has_key}}...{{/unless}}` | Shows text only if a condition is false | [Conditions](/dynamic-text/#conditions) |
| `=`, `!=`, `>`, `>=`, `<`, `<=` | Comparisons | [Conditions](/helpers-reference/#conditions) |
| `and`, `or`, `not` | Combine conditions | [Conditions](/helpers-reference/#conditions) |
| `+`, `-`, `*`, `/`, `%` | Calculations. Put spaces around `-` and `/` | [Calculations](/helpers-reference/#calculations) |
| `{{set "gold" 10}}`, `{{inc "gold" 5}}`, `{{dec "gold"}}`, `{{unset "has_key"}}` | Change an attribute at that point in the text, so they respect `{{#if}}` | [Conditional attribute changes](/attributes/#conditional-attribute-changes) |
| `(seen "cave")`, `(visits "cave")`, `(at "cave")` | Whether the player has seen a section or passage, how many times, and whether they're there now | [Tracking sections and passages](/attributes/#tracking-sections-and-passages) |
| `turns` | The number of links the player has clicked in the whole story | [Counting turns](/attributes/#counting-turns) |
| `previous_section`, `previous` | The section, or the section or passage, the player saw before this one | [Where the player came from](/attributes/#where-the-player-came-from) |
| `{{embed "map"}}` | Shows the text of another section, or a passage in this one | [Embed text](/basic-concepts/#embed-text) |
| `{{embed "say" who="Ann"}}`, `{{#embed "box"}}...{{/embed}}` | Embeds text with parameters, or wrapping some text that it shows with `{{content}}` | [Parameters](/basic-concepts/#parameters), [Wrapping text](/basic-concepts/#wrapping-text) |
| `{{goto "cave"}}`, `{{goto "cave" after=3000}}` | Goes to another section without a click, straight away or after a delay in milliseconds (or a time like `"3s"`, or an expression) | [Go to another section](/basic-concepts/#go-to-another-section) |
| `{{#every 1000}}...{{/every}}`, `{{stop}}` | Shows some text again and again while the player is in the section, until a `{{stop}}` | [Repeating text](/dynamic-text/#repeating-text) |
| `{{restart text="Play again"}}`, `{{saves}}`, `{{settings}}` | Links that restart the story, open the Saved games dialog, or open the Settings dialog | [Restarting and saving from the story](/basic-concepts/#restarting-and-saving-from-the-story) |
| `{{deactivate "door"}}`, `{{deactivate}}` | Turns off the links to a passage in this section, or to this passage | [Turning off passage links](/basic-concepts/#turning-off-passage-links) |
| `{{random (array "a" "b")}}` | Picks one at random | [Random](/dynamic-text/#random) |
| `{{rotate (array "a" "b") set="x"}}` | A link that cycles through options | [Rotate](/dynamic-text/#rotate) |
| `{{sequence (array "a" "b")}}` | A link that goes through options once | [Sequence](/dynamic-text/#sequence) |
| `{{live "score"}}` | Shows an attribute, and updates when it changes | [Live](/dynamic-text/#live) |
| `{{#animate "typewriter"}}...{{/animate}}` | Animates some text. Also `toast`, `fadeIn` and `continue` | [Animation](/dynamic-text/#animation) |
| `{{#style "shudder"}}...{{/style}}` | Gives some text an effect that lasts, such as `shudder`, `flicker` or `blur`, or a class for your CSS | [Text effects](/dynamic-text/#text-effects) |
| `{{addclass "dark"}}`, `{{removeclass "dark"}}`, `{{toggleclass "dark"}}`, `(hasclass "dark")` | Change and check the classes on the story, for your CSS | [Class helpers](/helpers-reference/#class-helpers) |
| `{{stopsounds}}` | Stops the sounds playing once, as `@sound stop` does | [Music and sound](/images-and-files/#music-and-sound) |
| `{{#label "x"}}...{{/label}}`, `{{#replace "x"}}...{{/replace}}` | Marks some text, and replaces it later | [Replace](/dynamic-text/#replace) |
| `{{section "cave" text="Go in"}}`, `{{passage "look"}}` | Links, made by a helper | [Creating links with helpers](/attributes/#creating-links-with-helpers) |
| `(array "a" "b")`, `{{append "bag" "key"}}`, `(contains "bag" "key")` | Arrays | [Array management helpers](/helpers-reference/#array-management-helpers) |
| `{ hp: 10, name: "Ann" }`, `hero.hp`, `["a", "b"]`, `party[0].name` | Objects and arrays in expressions, and the values inside them | [Objects](/attributes/#objects) |
| `{{!-- a comment --}}` | A comment, which the player doesn't see | [Text processing](/helpers-reference/#text-processing) |
| `{{!-- squiffy-ignore dead-end --}}` | Turns off a warning, for the section it's in, or in the master section for the whole story | [Turning off a warning](/cli/#turning-off-a-warning) |

## Formatting

Text is [Markdown](https://daringfireball.net/projects/markdown/syntax): `**bold**`, `_italic_`, lists, headings and so on. Leave a blank line between paragraphs, as a single line break is just a space. You can use HTML too, such as `<span style="color: red">`, and images, sound and video: see [Images, sound and other files](/images-and-files/).

`<input data-attribute="name">` asks the player for some text, and stores it in an attribute. Add `data-section="next"` or `data-passage="next"` to go there when the player presses Enter: see [Player input](/player-input/).

## squiffy.json

The project file, which makes a folder of `.squiffy` files one story. See [Stories in several files](/multiple-files/), and for the buttons, panels and settings it sets, [Buttons, panels and settings](/buttons-panels-settings/).

| Property | What it does |
|---|---|
| `"version": 1` | The version of the file's format. Required |
| `"main": "story.squiffy"` | The story's main file, where it starts. Required |
| `"exclude": ["drafts/**"]` | `.squiffy` files that aren't part of the story |
| `"id": "…"` | Identifies the story, so a saved game can only be loaded into the story it came from. See [Saved games](/buttons-panels-settings/#saved-games) |
| `"saveButton": false` | Leaves out the Save button and its Saved games dialog. See [Saved games](/buttons-panels-settings/#saved-games) |
| `"backButton": false` | Leaves out the Back button for players. See [The Back button](/buttons-panels-settings/#the-back-button) |
| `"settings"` | Options the player can change at any time, such as text size or content warnings, from a Settings button. See [Player settings](/buttons-panels-settings/#player-settings) |
| `"panels"` | Passages that are always to hand, such as the player's stats or inventory: beside the story, or in a dialog from a button in the header. See [Panels](/buttons-panels-settings/#panels) |
| `"strings"` | The text of the page's buttons, for a story in another language. See [The page's text in another language](/buttons-panels-settings/#the-pages-text-in-another-language) |
| `"map"` | Where you've put things on the editor's story map. The editor writes this |
